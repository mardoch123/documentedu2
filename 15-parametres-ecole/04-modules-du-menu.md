# 🧩 Afficher / masquer des modules du menu

## 🎯 Rôle
Toutes les écoles n'utilisent pas tous les modules (cantine, bibliothèque, transport, santé…).
Cette page vous laisse **choisir les entrées visibles dans votre menu latéral** : un module
**masqué** disparaît du menu pour **votre compte** (données conservées), et peut être
**ré-affiché** à tout moment. La page montre aussi les **nouveaux menus** disponibles que
vous pouvez **ajouter à vos modules**.

## ✅ Prérequis
1. Être **School Admin**.
2. Le module doit être **inclus dans votre abonnement** : un module non souscrit reste
   invisible/masquable selon le forfait.
3. Accès : **Paramètres → Modules du menu** (`school-settings.modules-visibility`).

## 🟢 Masquer / afficher un module (étape par étape)
1. Ouvrez **Modules du menu** : chaque tuile = un module, avec un **interrupteur**.
2. **Éteignez** l'interrupteur des modules que vous ne voulez **pas voir** ; **allumez** ceux
   dont vous avez besoin.
3. Utilisez la **recherche** (insensible aux accents) pour retrouver un module vite.
4. Cliquez sur la **barre « Enregistrer »** (en bas) (`school-settings.modules-visibility.save`).
5. Le **menu latéral se met à jour immédiatement**.

## ➕ Ajouter un nouveau module au paramétrage
1. Si un menu récent n'apparaît pas encore dans la liste, la page le signale avec un bouton
   **« Ajouter à mes modules »** (`school-settings.modules-visibility.register`).
2. Cliquez : le module rejoint la liste des modules **paramétrables** de votre école.

## ✏️ Modifier / 🔴 Supprimer / ♻️ Restaurer
- **Masquer ≠ supprimer** : les **données du module restent intactes** ; seul l'accès menu
  change. **Ré-afficher** (interrupteur ON) = la « restauration » de l'accès, instantanée.
- ⚠️ Le réglage est **stocké par compte utilisateur** : un autre membre du personnel peut
  voir un menu que vous avez masqué pour vous. Pour masquer à **toute l'école**, passez par
  les **rôles/permissions** (*module Personnel*) ou le Support.

## ⚠️ Bon à savoir
- **Alléger le menu** aide le personnel à ne pas se perdre : masquez ce que vous n'utilisez
  jamais (ex. Santé si pas d'infirmerie).
- Certains modules **essentiels** (Tableau de bord, Élèves) ne se masquent pas.
- Un module masqué reste **facturé** s'il est dans votre abonnement : pour le **retirer
  vraiment**, contactez le Support EduEasy (*page Abonnement, 15*).
- La **version mobile** du menu suit le même réglage dans l'app de direction.
