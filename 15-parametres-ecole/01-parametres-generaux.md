# ⚙️ Paramètres généraux de l'école (identité, logo, coordonnées)

## 🎯 Rôle
C'est la **carte d'identité numérique** de votre établissement : **nom**, **logo**,
**coordonnées** (adresse, téléphone, email), **exercice financier** (période de facturation)
et divers réglages qui apparaissent **partout** dans l'application — factures, reçus,
bulletins, certificats, site web, applications mobiles. Une erreur ici se répercute
**sur tous les documents**.

## ✅ Prérequis
1. Être **School Admin** (le menu Paramètres est protégé, inaccessible aux enseignants).
2. Disposer des **informations officielles** de l'école et d'un **fichier logo** (PNG/JPG,
   fond transparent de préférence).
3. Accès : menu **Settings / Paramètres** (`school-settings.index`).

## 🟢 Configurer les paramètres généraux (étape par étape)
1. Ouvrez **Paramètres** (liste des pages de réglage).
2. Renseignez la section **identité** :
   - **Nom de l'école** (tel qu'il doit apparaître sur les documents officiels) ;
   - **Adresse**, **téléphone(s)**, **email** officiel ;
   - **Logo** : téléversez le fichier image ;
   - **Slogan / présentation** éventuels.
3. Réglez l'**exercice financier** (année de facturation) si demandé.
4. Faites **défiler jusqu'au bas** et cliquez **Update / Enregistrer**
   (`school-settings` → `update`). Un message de succès confirme.

## ✏️ Modifier plus tard
1. Retournez dans **Paramètres**, changez les champs voulus, **enregistrez** à nouveau.
2. ⚠️ Le **changement de nom/logo** s'applique aux **nouveaux documents** ; les PDF déjà
   imprimés ne changent pas rétroactivement.

## 🔴 Supprimer / ♻️ Restaurer
- Ces réglages **ne se suppriment pas** : ils existent toujours (au pire **par défaut**).
  Pour **annuler** une modification, **remettez l'ancienne valeur** et enregistrez.
- ⚠️ En bas de page existent des actions **irréversibles** de fermeture de compte
  (`school-settings.deactivate-forever`, `delete-account`, `delete-account-permanent`) :
  **ne jamais cliquer sans échange préalable avec le Support EduEasy**.

## ⚠️ Bon à savoir
- **Enregistrez avant de changer d'onglet** : un formulaire non sauvegardé perd ses saisies.
- **Logo** : image **carrée nette**, poids léger — il orne reçus, cartes et site web.
- **Email officiel** : c'est celui qui reçoit les confirmations système ; vérifiez la
  **boîte de spam** si rien n'arrive.
- La **devise** et le **format des identifiants** ont leur propre page (*03* et *05*).
- Après toute modification majeure, **contrôlez un reçu/bulletin test** pour voir le rendu.
