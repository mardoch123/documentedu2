# 📣 Publier une annonce (communication vers les classes)

## 🎯 Rôle
L'**annonce** est un message que la direction (ou un enseignant) **adresse à une ou
plusieurs classes**, avec possibilité de **joindre des fichiers** (image ou document) et un
**lien**. Elle apparaît dans l'espace des élèves/parents/concernés. C'est l'outil idéal pour
une information ciblée par classe : sortie pédagogique, réunion de parents, changement
d'horaire, consigne de devoirs, etc.

> Différence à retenir :
> - **Annonce** = ciblée par **classes/sections** (+ fichiers), visible des familles des
>   classes choisies.
> - **Notification** = ciblée par **rôles** (tous les parents, tous les profs…), voir
>   *07-notifications.md*.

## ✅ Prérequis
1. Avoir l'option d'abonnement « **Announcement Management** ».
2. Permission de création d'annonce (direction ; les **enseignants** publient aussi, avec en
   plus un choix de **Matière**).
3. Avoir **créé les classes/sections** et l'**année scolaire** (filtre obligatoire).
4. Accès : menu latéral **Communication → Annonces**.

## 🟢 Créer une annonce (étape par étape)
1. Ouvrez le menu **Annonces**. En haut de page, le bloc **« Créer une annonce »** est ouvert.
2. Renseignez :
   - **« title »** ★ — le titre de l'annonce (court et clair) ;
   - **« description »** — le message détaillé ;
   - **Fichiers** — joignez une **image** ou un **document** (formats image/doc acceptés) ;
   - cochez **« add_url »** si vous voulez ajouter un **lien cliquable** ;
   - **« class_sections »** ★ — la/les **classe(s)/section(s)** destinataires.
     Cliquez **« Select All »** pour viser **toutes les classes** d'un coup.
   - *(Enseignant uniquement)* : choisissez aussi la **Matière** concernée.
3. Cliquez sur **« submit »** (bouton de validation).
4. L'annonce apparaît aussitôt dans la **liste** en dessous et est **visible par les familles**
   des classes sélectionnées.

## 📋 Consulter la liste des annonces
- Le tableau **« Liste des annonces »** affiche : **N°, Titre, Description, Destinateurs
  (classes), Fichiers, Actions**.
- Filtre obligatoire en haut : **Année scolaire** (★). Les enseignants ajoutent un filtre
  **Classe**.
- Utilisez la **recherche**, le **rafraîchissement**, l'**export** (les colonnes et le bouton
  en haut à droite du tableau) pour retrouver une annonce. Le fichier exporté s'appelle
  `announcement-list-date`.

## ✏️ Modifier une annonce
1. Sur la ligne de l'annonce, cliquez l'**icône Modifier** (colonne Actions).
2. La fenêtre **« Modifier l'annonce »** s'ouvre avec les champs pré-remplis
   (titre, description, classes, fichier).
3. Corrigez puis **enregistrez**. La version modifiée s'applique immédiatement.

## 🔴 Supprimer une annonce (mise à la corbeille)
1. Sur la ligne, cliquez l'**icône Supprimer**.
2. Confirmez. L'annonce est **mise à la corbeille** (elle disparaît de la liste active mais
   **n'est pas définitivement effacée**).
3. Pour retrouver les annonces à la corbeille, basculez le sélecteur de liste en
   **« Trashed »** (à côté de « all ») au-dessus du tableau.
4. Pour **supprimer définitivement** un fichier joint sans toucher à l'annonce, utilisez
   l'action de **suppression de fichier** sur la pièce concernée.

## ♻️ Restaurer une annonce supprimée
Contrairement à beaucoup d'autres modules, **l'annonce peut être restaurée** :
1. Basculez la liste en mode **« Trashed »** (bouton de filtre au-dessus du tableau).
2. Sur l'annonce à récupérer, cliquez l'**icône Restaurer**.
3. L'annonce **revient dans la liste active** et redevient visible des classes destinataires.

## ⚠️ Bon à savoir
- **Une annonce supprimée reste restaurable** : pas de panique si vous vous trompez de
  classe destinataire — supprimez, puis recréez (ou restaurez l'ancienne et corrigez-la).
- Le champ **Classes** est **obligatoire** : sans destinataire, l'annonce ne peut pas être
  enregistrée.
- Les **fichiers lourds** ralentissent l'affichage sur mobile des parents : privilégiez des
  images compressées et des PDF légers.
- **Annonce ≠ notification SMS/WhatsApp** : l'annonce est vue dans l'application ; pour
  prévenir massivement par rôle, utilisez les notifications ou les modules de messagerie.
