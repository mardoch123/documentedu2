# Rapports Ministériels & EducMaster

## 🎯 Rôle
Générer en quelques clics les **documents officiels que l'administration (ministère,
inspection) exige des écoles** : états deeffectifs, rapports d'année, fichiers au format
EducMaster… EduEasy assemble les données (élèves, notes, présences, personnel) et produit
le document au format attendu.

## ✅ Prérequis
- Données à jour : **élèves** avec actes de naissance/sexes, **classes**, **notes
  publiées**, **présences**, **enseignants** avec leurs matières.
- Accès : menu **Académique → Rapports Ministériels & EducMaster**.

## 🟢 Générer un rapport (étape par étape)
1. Ouvrez **Rapports Ministériels**.
2. Choisissez le **type de document** dans la galerie (ex. « État de effectifs annuel »,
   « Rapport d'inspection », « Fichier EducMaster »).
3. Réglez la **période** : année scolaire, semestre, date d'arrêté.
4. Sélectionnez le **périmètre** : toutes les classes ou certaines classes/sections.
5. Cliquez sur **Générer / Aperçu**.
6. L'aperçu s'affiche : contrôlez les totaux (nombre d'élèves, répartition F/G).
7. Cliquez sur **Télécharger** :
   - **PDF** pour signature et dépôt papier ;
   - **Excel / CSV** pour import dans le portail du ministère ;
   - **EducMaster** (format structuré) si le document le prévoit.
8.archivez le fichier téléchargé (clé USB, email à la direction).

## ✏️ Corriger un chiffre faux dans un rapport
Le rapport n'est qu'une **photo des données**. Un effectif faux se corrige toujours à la
source :
1. Repérez la classe ou l'élève concerné dans l'aperçu ;
2. Allez dans le module d'origine (Élèves, Présences, Examens) et corrigez ;
3. **Relancez la génération** : le nouveau fichier intègre la correction.

## 🔴 Supprimer un rapport généré
Les rapports générés ne sont pas stockés comme des fiches (sauf historique éventuel de la
page) : **rien à supprimer** — fermez l'aperçu. Si un historique existe, icône **poubelle 🗑**
sur la ligne du rapport → confirmer.

## ♻️ Retrouver un rapport passé
1. Ouvrez l'onglet **« Historique »** de la page (s'il existe dans votre version).
2. Sinon : régénérez le rapport avec **la même période et le même type** — les données
   étant les mêmes, le fichier sera identique.

## ⚠️ Bon à savoir
- Générez vos rapports **après la délibération finale** (notes publiées), sinon les
  moyennes du document seront fausses.
- Conservez précieusement chaque fichier téléchargé : c'est votre preuve de dépôt.
- Un rapport qui échoue (« Aucune période définie ») = il manque un semestre ou une
  année active : créez-le d'abord.
