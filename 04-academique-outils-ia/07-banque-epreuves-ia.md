# Banque d'Épreuves IA (APC)

## 🎯 Rôle
Constituer un **stock de questions et d'examens prêts à l'emploi**, alignés sur l'approche
par les compétences (APC) : l'IA génère des questions à partir du **programme (syllabus)**
d'une matière, vous les trievez, puis composez une épreuve équilibrée en quelques clics.

## ✅ Prérequis
- **Matières affectées** aux classes + **syllabus** renseignés
  ([09-syllabus.md](../03-academique-structure/09-syllabus.md)) — c'est la matière première de l'IA.
- Accès : menu **Académique → Banque d'Épreuves IA (APC)**.

## 🟢 Créer une banque et générer des questions
1. Ouvrez **Banque d'Épreuves IA**.
2. Cliquez sur **Nouvelle banque** : nom (ex. `Maths 5ème — T1`), classe, matière, semestre.
3. Dans la banque, cliquez sur **Générer des questions (IA)**.
4. Précisez la demande :
   - **chapitres/compétences** visés ;
   - **type** : QCM, vrai/faux, exercice à réponse ouverte, problème de situation ;
   - **difficulté** : facile / moyen / difficile ;
   - **quantité** souhaitée (ex. 10).
5. Cliquez sur **Générer** (attendez 30 à 90 secondes).
6. **Relisez chaque question** : l'IA peut faire des erreurs de calcul. Corrigez avec le
   crayon ✏️, ou rejetez avec la poubelle 🗑.
7. Les questions validées restent stockées dans la banque pour toute l'année.

## 🟢 Composer une épreuve à partir de la banque
1. Dans la banque → bouton **Créer une épreuve / Composer**.
2. Cochez les questions retenues (l'outil affiche le total de points calculé automatiquement).
3. Ajustez les **barèmes** par question si besoin.
4. Cliquez sur **Générer le sujet** : un **PDF imprimable** (avec en-tête de l'école,
   nom/date cachés pour la copie) et le **corrigé** séparé sont produits.
5. Téléchargez, imprimez. L'épreuve peut aussi être envoyée directement en **examen en ligne**.

## ✏️ Modifier une question / une épreuve
- Question : icône **crayon ✏️** dans la liste des questions → corriger énoncé, réponses,
  barème → **Soumettre**.
- Épreuve : ouvrez-la → ajoutez/retirez des questions → régénérez le PDF.

## 🔴 Supprimer
- Une **question** : icône **poubelle 🗑** sur sa ligne (elle disparaît de la banque).
- Une **épreuve composée** : poubelle 🗑 sur la ligne de l'épreuve.
- Une **banque entière** : poubelle 🗑 → ⚠️ cela supprime aussi toutes ses questions.

## ♻️ Restaurer
Utilisez le filtre **« Trashed »** de la page (questions ou banques) → icône
**restaurer ♻️** → confirmez. Une épreuve supprimée se recompose en 2 minutes si ses
questions sont encore dans la banque : c'est la parade à tout.

## ⚠️ Bon à savoir
- Gardez au moins **2 jeux de questions différents par chapitre** : le jour J, l'anti-triche
  (voir [10-anti-triche](../09-examens/10-anti-triche-repartition.md)) pourra composer des
  sujets variés par salle.
- Le moteur IA peut être temporairement indisponible (quota, panne) : l'outil bascule
  automatiquement sur un moteur de secours ; si tout échoue, vos questions déjà stockées
  restent utilisables — la banque fonctionne hors IA une fois remplie.
- Une question générée deux fois se déduplique manuellement : gardez la meilleure version.
