# Les Filières (Streams)

## 🎯 Rôle
Une **filière** (Stream) désigne l'**orientation** des élèves d'un niveau :
« Sciences », « Littéraire », « Technique », « Gestion »… Utile surtout à partir du secondaire ;
au primaire, vous pouvez n'avoir qu'une seule filière « Unique ».

## ✅ Prérequis
- Accès : menu **Académique → Stream**. Permission « stream-list ».

## 🟢 Créer une filière
1. Menu **Académique → Stream**.
2. Dans le formulaire du haut, tapez le **Nom** de la filière (ex. `Sciences Expérimentales`).
3. Cliquez sur **Soumettre**.
4. La filière apparaît dans la liste en dessous.

## ✏️ Modifier une filière
1. Icône **crayon ✏️** sur la ligne concernée de la liste.
2. Corrigez le nom dans la fenêtre qui s'ouvre → **Soumettre**.

## 🔴 Supprimer une filière
1. Icône **poubelle 🗑** → confirmer → direction la corbeille.

⚠️ Si des classes sont rattachées à cette filière, modifiez d'abord leur filière
(page Classes → modifier) avant de supprimer.

## ♻️ Restaurer une filière supprimée
1. Cliquez sur le filtre **« Trashed »** au-dessus de la liste.
2. Icône **restaurer ♻️** sur la ligne → confirmez.
3. Vérifiez dans l'onglet **« All »** que la filière est revenue.

## ⚠️ Bon à savoir
- Lors de la création d'une **classe**, vous pouvez cocher des sections **par filière** :
  chaque filière sélectionnée reçoit sa propre liste de sections.
- Les filières apparaissent dans les **bulletins** et les **exports Excel** des élèves :
  gardez des noms normalisés (évitez les majuscules complètes, les accents manquants).
