# Les Groupes de classes (Class Group)

## 🎯 Rôle
Un **groupe de classes** rassemble plusieurs classes ou sections qui suivent **le même
programme ou le même emploi du temps** : par exemple regrouper « 2nde A » et « 2nde B »
pour un cours commun, ou créer un groupe « Terminales » pour les matières optionnelles.
C'est aussi l'unité utilisée pour affecter certaines **matières optionnelles**.

## ✅ Prérequis
- Des **classes** et **sections** existantes → [07-classes.md](07-classes.md).
- Permission « class-group-list ».
- Accès : menu **Académique → Class Group**.

## 🟢 Créer un groupe de classes
1. Menu **Académique → Class Group** → zone de création en haut de page.
2. Indiquez le **Nom du groupe** (ex. `Communes 2nde`).
3. Sélectionnez les **classes/sections membres** dans la liste
   (champ à sélection multiple — maintenez Ctrl sur PC, Cmd sur Mac pour en choisir
   plusieurs).
4. Cliquez sur **Soumettre**.
5. Le groupe apparaît dans la liste avec ses membres.

## ✏️ Modifier un groupe
1. Icône **crayon ✏️** sur la ligne du groupe.
2. Ajoutez ou retirez des classes membres (cases à cocher), changez le nom si besoin.
3. **Soumettre** pour enregistrer.

## 🔴 Supprimer un groupe
1. Icône **poubelle 🗑** → confirmer.

⚠️ Conséquence à connaître : si des **affectations de matières optionnelles** ou des
**emplois du temps** utilisent ce groupe, elles se retrouvent orphelines.
Reportez-les sur un autre groupe avant suppression.

## ♻️ Restaurer un groupe supprimé
1. Ouvrez le filtre **« Trashed »** en haut de la liste des groupes.
2. Cliquez sur l'icône **restaurer ♻️** de la ligne concernée → confirmez.
3. Vérifiez que les membres sont bien revenus dans le groupe (onglet « All »).

## ⚠️ Bon à savoir
- Un groupe n'héberge **pas d'élèves directement** : les élèves restent dans leur classe ;
  le groupe est une étiquette commune pour l'organisation des cours.
- Utile aussi pour les **examens communs** : une salle d'examen peut être définie par groupe.
