# Les Sections (A, B, C…)

## 🎯 Rôle
Une **section** est le groupe d'élèves à l'intérieur d'une même classe :
« 6ème **A** », « 6ème **B** »… Vous créez d'abord la liste des lettres/noms de sections,
puis vous les affectez à chaque classe.

## ✅ Prérequis
- Être directeur (School Admin) ou avoir la permission « section-list ».
- Accès : menu **Académique → Section**.

## 🟢 Créer une section
1. Menu **Académique → Section**.
2. Dans le formulaire du haut, tapez le **Nom** de la section (obligatoire) : `A`, `B`, `C`…
3. Cliquez sur **Soumettre**.
4. La section apparaît dans la liste. Créez toutes vos lettres d'un coup (une par une).

💡 Vous pouvez aussi en créer « en trop » : seules les sections cochées **au moment de créer
la classe** seront réellement utilisées pour cette classe.

## ✏️ Modifier une section
1. Dans la liste, icône **crayon ✏️** sur la ligne concernée.
2. Corrigez le nom dans la fenêtre qui s'ouvre, puis **Soumettre**.

## 🔴 Supprimer une section
1. Icône **poubelle 🗑** sur la ligne, puis confirmer.
2. La section passe en corbeille (visible via le filtre **« Trashed »** en haut de la liste).

⚠️ Si des élèves sont actuellement placés dans cette section, commencez par les déplacer
vers une autre section (page de modification de l'élève) pour éviter des affichages vides.

## ♻️ Restaurer une section supprimée
1. Filtre **« Trashed »** → retrouvez la section.
2. Icône **restaurer ♻️** → confirmez.
3. Repassez sur **« All »** pour vérifier le retour.

## ⚠️ Bon à savoir
- Les sections servent aussi de filtre dans les **bulletins**, les **emplois du temps**
  et les **présences** : gardez des noms courts et clairs (A, B, C…).
- Astuce : créez aussi une section **« NAS »** (non affecté) si vous recevez des élèves
  en cours d'année sans place définie tout de suite.
