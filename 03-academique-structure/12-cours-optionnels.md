# Les matières optionnelles (Assign Elective Subject)

## 🎯 Rôle
Certains élèves choisissent des **matières optionnelles** (latin, sport d'établissement,
informatique approfondie…) au lieu d'être imposées à toute la classe.
Cette page **affecte une option à un élève précis** et permet de gérer les groupes d'option.

## ✅ Prérequis
1. La matière optionnelle doit exister dans le **référentiel des matières**
   ([03-matieres.md](03-matieres.md)).
2. Les **élèves** doivent être admis ([06-eleves](../06-eleves/02-admettre-un-eleve.md)).
3. Permission « assign-elective-subject-list ».

Accès : menu **Académique → Assign Elective Subject**.

## 🟢 Affecter une option à un élève
1. Ouvrez la page **Assign Elective Subject**.
2. Cliquez sur **Ajouter / Assigner**.
3. Sélectionnez :
   - l'**élève** (tapez son nom ou son matricule dans le champ de recherche) ;
   - la **classe/section** de l'élève (se remplit souvent automatiquement) ;
   - la **matière optionnelle** choisie par l'élève.
4. Cliquez sur **Soumettre**.
5. Une ligne « Élève — Option — Classe » apparaît dans la liste.

## ✏️ Changer l'option d'un élève
1. Retrouvez sa ligne dans la liste (loupe : tapez le nom de l'élève).
2. Icône **crayon ✏️** → sélectionnez la nouvelle matière optionnelle → **Soumettre**.

## 🔴 Retirer une option (supprimer l'affectation)
1. Icône **poubelle 🗑** sur la ligne → confirmer.
2. L'élève reste dans sa classe ; seule l'option est retirée.

## ♻️ Restaurer une affectation supprimée
1. Utilisez le filtre **« Trashed »** en haut de la liste (si votre version l'affiche).
2. Cliquez sur **restaurer ♻️** sur la ligne concernée et confirmez.
3. À défaut de corbeille visible : recréez l'affectation (même élève, même option)
   en 30 secondes via le formulaire « Ajouter ».

## ⚠️ Bon à savoir
- Les options apparaissent sur les **bulletins** des élèves qui les suivent, avec leur note.
- Planifiez les options **avant** de créer l'emploi du temps : les créneaux d'option sont
  souvent communs à plusieurs classes.
- Un élève sans option affichée alors qu'il en a choisi une = vérifiez d'abord cette page,
  c'est presque toujours un oubli d'affectation.
