# Les Programmes (Syllabus)

## 🎯 Rôle
Le **syllabus** décrit **le contenu à enseigner** : une matière, une classe, un semestre,
et la liste des thèmes/leçons prévus, avec leurs dates. C'est la « carte routière » de
l'année pour chaque matière ; les enseignants s'y réfèrent pour remplir leurs fiches de cours.

## ✅ Prérequis
1. Classes et matières affectées à la classe (voir [08](08-matieres-de-classe.md)).
2. Un semestre actif.
3. Permission « syllabus-list » (accessible aussi au School Admin).

Accès : menu **Académique → Syllabus**.

## 🟢 Créer un syllabus
1. Menu **Académique → Syllabus** → bouton **Ajouter / Créer**.
2. Remplissez le formulaire :
   - **Classe / Section / Semestre** de destination ;
   - **Matière** concernée ;
   - **Titre / descriptif** du programme ;
   - **Période couverte** (dates de début et de fin si demandé).
3. Cliquez sur **Soumettre**.
4. Le syllabus apparaît dans la liste ; ouvrez-le (clic sur son titre ou l'icône œil 👁)
   pour y **ajouter les chapitres et leçons** qui le composent.

## ✏️ Modifier un syllabus
1. Dans la liste, icône **crayon ✏️** sur la ligne → corrigez → **Soumettre**.
2. Pour ajouter/enlever des leçons dans un syllabus existant : ouvrez-le et utilisez les
   boutons d'ajout/suppression de la liste interne.

## 🔴 Supprimer un syllabus
1. Icône **poubelle 🗑** → confirmer.
2. La suppression n'efface **pas** les fiches de cours déjà rédigées par les profs :
   elle retire seulement le programme de référence.

## ♻️ Restaurer
Le module Syllabus utilise la corbeille standard si votre version l'affiche :
filtre **« Trashed »** en haut de la liste → icône **restaurer ♻️**.
Sinon : **recréez le syllabus** avec les mêmes classe/matière/semestre — les leçons déjà
validées restent dans le système et pourront être re-liées.

## ⚠️ Bon à savoir
- Un bon réflexe en début d'année : créer **un syllabus par matière et par classe**,
  même succin (titre + période). Les enseignants ne peuvent pas toujours remplir leurs
  fiches de préparation sans programme de référence.
- Les syllabus servent aussi à la **banque d'épreuves IA** et aux **cahiers de vacances IA** :
  plus ils sont précis, meilleures sont les générations automatiques.
