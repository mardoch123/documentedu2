# Les Médiums (langues d'enseignement)

## 🎯 Rôle
Un **médium** définit la langue principale d'enseignement d'une classe :
« Français », « Anglais », « Bilingue »… Chaque classe et chaque matière y est rattachée.
C'est **la toute première chose** à créer avant les classes.

## ✅ Prérequis
- Être **directeur (School Admin)** ou avoir la permission « medium-list ».
- Chemin d'accès : menu **Académique → Medium**.

## 🟢 Créer un médium
1. Ouvrez le menu **Académique** puis cliquez sur **Medium**.
2. En haut de la page, dans le cartouche « Créer », tapez le **Nom** du médium
   (champ obligatoire, marqué d'un ★ rouge), ex. `Bilingue`.
3. Cliquez sur le bouton **Soumettre** (Submit).
4. Le message vert « Done Successfully » apparaît et le médium s'ajoute à la liste en dessous.

Répétez l'opération pour chaque langue utilisée dans l'école (2 ou 3 suffisent en général).

## ✏️ Modifier un médium
1. Dans la **liste des médiums** (en bas de page), retrouvez la ligne concernée
   (utilisez la recherche au-dessus du tableau).
2. Cliquez sur l'icône **crayon ✏️** dans la colonne « Action ».
3. Une petite fenêtre (modale) s'ouvre avec le nom actuel ; corrigez-le.
4. Cliquez sur **Soumettre / Mettre à jour**. La liste se rafraîchit.

## 🔴 Supprimer un médium
1. Dans la liste, cliquez sur l'icône **poubelle 🗑** de la colonne « Action ».
2. Une fenêtre demande de confirmer : cliquez sur **OK / Supprimer**.
3. Le médium disparaît de la liste « Toutes » : il est allé dans la **corbeille**,
   il n'est pas détruit.

⚠️ Ne supprimez pas un médium utilisé par des classes existantes : commencez par
créer le nouveau, réaffectez les classes (voir page Classes), puis supprimez l'ancien.

## ♻️ Restaurer un médium supprimé
1. Sur la même page, au-dessus de la liste, cliquez sur le filtre **« Trashed »** (Corbeille).
   Seuls les médiums supprimés s'affichent.
2. Sur la ligne du médium à récupérer, cliquez sur l'icône **restaurer ♻️** (colonne Action).
3. Confirmez. Repassez sur **« All / Toutes »** : le médium est de retour.

## ⚠️ Bon à savoir
- Le petit **bouton d'export** (icône d'extraction) au-dessus du tableau permet de
  télécharger la liste complète en Excel/CSV.
- La **roue ↻** en haut du tableau recharge les données sans rafraîchir toute la page.
