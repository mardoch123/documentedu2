# ↔️ Transférer un élève vers une autre école (Transferts externes)

## 🎯 Rôle
Ce module permet de **transférer le dossier complet d'un élève vers une autre école** :
- **Transfert interne** : vers une école qui utilise aussi EduEasy. Le dossier (identité,
  notes, historique, parents) part directement d'une école à l'autre, sans papier.
- **Transfert externe** : vers une école « classique » (hors EduEasy). Le système envoie
  une **invitation par email** à cette école, qui peut y télécharger le **dossier PDF complet**.
C'est aussi ici que vous **recevez** les élèves que d'autres écoles EduEasy vous transfèrent.

## ✅ Prérequis
1. L'élève doit déjà avoir une **fiche élève** dans votre école (module Élèves).
2. Permission « transfer-student-create ».
3. Pour un transfert interne : l'école de destination doit être inscrit sur EduEasy
   (vous la trouverez par son nom dans la recherche).
4. Pour un transfert externe : il faut l'**adresse email valide** de l'école destinataire.

## 🟢 Comment lancer un transfert (étape par étape)
1. Allez dans le menu **Élèves → Liste des élèves**.
2. **Cliquez sur le nom de l'élève** concerné : un panneau d'actions s'ouvre.
3. Choisissez l'action **Transférer** : la fenêtre « Transférer [prénom nom] » apparaît.
4. Sélectionnez le **Type de transfert** :
   - **Interne (Vers une école EduEasy)** : tapez le nom de l'école de destination dans la
     case « Rechercher l'école » (au moins 3 caractères), puis cliquez sur le bon résultat
     dans la liste qui se déroule. Un bandeau bleu rappelle que le dossier complet sera
     transféré directement.
   - **Externe (Invitation par email)** : saisissez (optionnel) le **Nom de l'école** et
     (obligatoire) l'**Email de l'école**. Un bandeau jaune prévient qu'une invitation sera
     envoyée à cette adresse pour télécharger le dossier PDF.
5. Cliquez sur **Confirmer le transfert**.
6. Dans la liste des élèves, l'élève affiche alors un badge :
   - **« Transfert en cours »** (jaune) pendant l'attente,
   - puis **« Apprenant transféré avec succès »** (vert, nom barré) une fois terminé —
     l'élève ne compte alors plus dans vos effectifs.

## 📥 Comment recevoir un élève qu'une autre école vous envoie
1. Allez dans le menu **Académique → Mobilité & Parcours → Transferts**
   (onglet **« Reçues »** : *Transferts entrants*).
2. La liste montre les demandes reçues : date, élève, école source, classe précédente.
3. **Cliquez sur la demande** pour ouvrir le **« Dossier de transfert »** : vous consultez
   le dossier complet **avant de décider**.
4. Choisissez la **« Classe de destination »** dans la liste déroulante ★ obligatoire.
5. Cliquez sur :
   - **✔ Valider & Intégrer** → l'élève rejoint votre école dans la classe choisie ;
   - **✘ Rejeter** → la demande revient à l'école émettrice avec votre motif.

## 📦 Suivre vos invitations envoyées
1. Même module, onglet **« Invitations envoyées »**.
2. Vous voyez en temps réel l'état de chaque invitation transmise aux écoles partenaires.
3. Bouton **PDF 📄** sur chaque ligne : télécharger le dossier de transfert PDF.
   (Lien « Retour aux élèves » pour relancer depuis la liste des élèves.)

## 🔴 Rejets et corrections (onglet « Rejetés »)
1. Onglet **« Rejetés »** : *Transferts rejetés*.
2. Chaque ligne affiche le **Motif** du rejet reçu — consultez-le avant de corriger.
3. Bouton **Retenter ↻** : dans un **délai de grâce de 30 jours**, le renvoi est
   **gratuit** ; passé ce délai, le bouton reste mais la règle de facturation change
   (barème de la plateforme).

## ✏️ Annuler / modifier un transfert
- Un transfert **en attente** ne se « modifie » pas : attendez le rejet (ou demandez-le à
  l'école destinataire) puis **relancez** depuis la fiche de l'élève avec les bonnes infos.
- Un transfert **validé** : l'élève est parti avec son dossier ; pour le récupérer, c'est
  l'autre école qui doit vous faire un transfert entrant, ou vous recréez la fiche
  (module **Élèves → Ajouter un élève**).

## ♻️ Restaurer après un transfert
- Un transfert réussi n'est **pas une suppression** : l'élève est archivé « transféré »
  (nom barré dans la liste). Si le transfert était une erreur, prévenez vite l'école
  destinataire pour qu'elle **rejette/intègre mal** — le plus simple reste de **recréer la
  fiche** ou de demander un transfert de retour via EduEasy Support.

## ⚠️ Bon à savoir
- Les badges de frais (**Frais payés / partiels / non payés**) sont visibles avant de
  transférer : réglez les impayés avec la famille avant, sinon le dossier part avec la dette.
- Un élève avec **« Transfert en cours »** n'est plus modifiable (la ligne est grisée) :
  c'est normal, il est « en route ».
- L'email généré automatiquement par la plateforme (badge « Généré ») suffit pour les
  transferts internes ; pour l'externe, mettez une vraie adresse d'école.
- Ce module est différent de **« Promouvoir / Transfert interne de classe »** (changement de
  classe dans la MÊME école) : voir la page *01-promouvoir-transférer-eleves-interne.md*.
