# Comprendre le menu latéral (la barre de gauche)

## 🎯 Rôle
Le **menu latéral** (à gauche de l'écran) est le « plan de l'immeuble » : toutes les pièces
d'EduEasy s'ouvrent depuis là. Savoir le lire, c'est déjà savoir se servir de l'application.

## 🧭 De quoi est composé le menu
De haut en bas :
1. **Votre carte d'identité** : photo, nom et rôle (ex. « School Admin », « Teacher »).
2. **Une barre de recherche** « Rechercher un menu… » : tapez un mot (ex. « bulletins ») et
   le menu se filtre instantanément pour montrer uniquement ce qui correspond.
3. **Des boutons de service** : « Réorganiser » (voir page suivante) et un bouton de repli.
4. **La liste des modules** : chaque ligne est une entrée du menu, avec une icône.
   - Une ligne avec une **flèche ▾** contient des **sous-menus** : cliquez dessus pour
     dérouler/replier la liste.
   - Une ligne **sans flèche** s'ouvre directement en clic.
5. En bas, toujours visible : le bouton vert **Support 24/7**.

## 🔒 Les menus avec cadenas et les menus absents
- **Cadenas 🟠** à côté d'un nom de menu = le module **n'est pas inclus** dans l'abonnement
  de l'école (ou est désactivé pour votre compte). Un clic affiche une information, mais la
  page est protégée. → Voyez avec la direction de l'école pour l'activer
  (menu *Paramètres de l'Établissement → Modules du menu*).
- **Menu qui n'existe pas du tout pour vous** = votre **rôle** ne donne pas accès à ce module.
  C'est normal et voulu (ex. un enseignant ne voit pas la gestion des salaires).

## 👥 Ce que voit chaque rôle ( résumé )
| Module (gros titres du menu) | Directeur (School Admin) | Enseignant | Staff/Secrétaire | Super Admin EduEasy |
|---|---|---|---|---|

| Académique (classes, matières…) | ✅ | 👁 lecture partielle | selon permissions | — |
| Élèves / Admissions | ✅ | selon « class-teacher » | ✅ secrétariat | — |
| Présences | ✅ | ✅ ses classes | ✅ | — |

| Frais & finances | ✅ si abonné | ❌ | selon permission | ✅ (salle des ventes plateforme) |
| Cantine / Transport / Bibliothèque / Santé / Mobilier | ✅ si abonné | partiel | partiel | — |
| Personnel & congés | ✅ | 👁 son dossier | partiel | ✅ RH interne |
| Gestion commerciale / Écoles / Abonnements | ❌ | ❌ | ❌ | ✅ |
| Paramètres (école ou système) | ✅ école | ❌ | ❌ | ✅ système SaaS |

## 🪄 Astuces utiles
- **Recherche du menu** : tapez « carte », « bulletin », « congé »… et seul ce qui compte
  s'affiche. Appuyez sur **Échap** pour tout réafficher.
- **Menu réduit en icônes** : l'icône en haut du menu permet de le « replier » en bande
  d'icônes pour laisser plus de place au travail. Survolez une icône pour voir son nom.
- Les **pastilles rouges** (chiffres) sur un menu indiquent des éléments à traiter
  (ex. actions commerciales à valider, transferts en attente).

## ⚠️ Bon à savoir
- Si une page vous ramène en boucle à la connexion : videz le cache du navigateur
  (Ctrl + Maj + R sur PC, Cmd + Maj + R sur Mac) puis reconnectez-vous.
- Le menu est le **même** sur ordinateur et tablette ; sur téléphone, ouvrez-le avec le
  bouton ☰ en haut à gauche.
