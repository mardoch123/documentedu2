# Abonnement

[Cli](https://app.guidde.com/share/playbooks/x9scpk1Gt6iNhAEk4RMCVP)[quer pour voir la vidéo](https://app.guidde.com/share/playbooks/x9scpk1Gt6iNhAEk4RMCVP)

Ce guide détaille les étapes nécessaires pour gérer les abonnements sur Edueasy. Suivez les instructions ci-dessous pour naviguer efficacement dans l'application et effectuer les actions requises.

#### Aller à [edueasy.net](https://edueasy.net/)

#### 1. Cliquez "Plans"

Accédez à l'onglet "Plans" pour voir votre plan actuel ainsi que toutes les fonctions auxquelles vous avez accès

<figure><img src="https://static.guidde.com/v0/qg%2FpOO86wzsXKMLqRP4iQ5el5UNXkR2%2Fx9scpk1Gt6iNhAEk4RMCVP%2Fwbcvio6xQ2N7m2Cik39XRo_doc.png?alt=media&#x26;token=37f2069d-79ce-4427-96cf-23a17fe1e81d" alt=""><figcaption></figcaption></figure>

#### 2. Cliquez "Mettre à jour le plan actuel"

Sélectionnez l'option pour mettre à jour le plan en cours; vous pouvez voir les fonctions auxquelles vous avez accès selon le plan et ainsi vous pourrez choisir simplement selon vos besoins

<figure><img src="https://static.guidde.com/v0/qg%2FpOO86wzsXKMLqRP4iQ5el5UNXkR2%2Fx9scpk1Gt6iNhAEk4RMCVP%2FnuJhTRK8ozuWekxS4xrdkX_doc.png?alt=media&#x26;token=f6f1718a-499d-46cf-a94c-50c0fac8c602" alt=""><figcaption></figcaption></figure>

#### 3. Cliquez "Oui"

Choisissez l'option "Oui"

<figure><img src="https://static.guidde.com/v0/qg%2FpOO86wzsXKMLqRP4iQ5el5UNXkR2%2Fx9scpk1Gt6iNhAEk4RMCVP%2FqyLemLRhZ28FyJjkAu5cro_doc.png?alt=media&#x26;token=de831681-a696-4096-bdf6-b3638b1b96cf" alt=""><figcaption></figcaption></figure>

#### 4. Cliquez "Oui"

Appuyez sur "Oui" pour confirmer

<figure><img src="https://static.guidde.com/v0/qg%2FpOO86wzsXKMLqRP4iQ5el5UNXkR2%2Fx9scpk1Gt6iNhAEk4RMCVP%2Fdi9Uw3UMH3sbhghFWPbHTh_doc.png?alt=media&#x26;token=c411a8f8-1564-4a23-ba4e-73a52d8d5292" alt=""><figcaption></figcaption></figure>

#### 5. Cliquez "PAYER"

Sélectionnez l'option de paiement

<figure><img src="https://static.guidde.com/v0/qg%2FpOO86wzsXKMLqRP4iQ5el5UNXkR2%2Fx9scpk1Gt6iNhAEk4RMCVP%2F36EMbm95QZtnJt4H8drdW9_doc.png?alt=media&#x26;token=e3133c6c-d090-4541-84af-3f735fe2767a" alt=""><figcaption></figcaption></figure>

#### 6. Cliquez "on"

Activez l'interrupteur en position "on"

<figure><img src="https://static.guidde.com/v0/qg%2FpOO86wzsXKMLqRP4iQ5el5UNXkR2%2Fx9scpk1Gt6iNhAEk4RMCVP%2Ftt1dbLYJzCoLqYuuxhinVM_doc.png?alt=media&#x26;token=1f551d94-aafe-4867-a593-231bd4175b33" alt=""><figcaption></figcaption></figure>

#### 7. Cliquez "Sélectionnez le pays Bénin Burkina-Faso Côte d'Ivoire Sénégal Togo"

Choisissez le pays dans la liste déroulante

<figure><img src="https://static.guidde.com/v0/qg%2FpOO86wzsXKMLqRP4iQ5el5UNXkR2%2Fx9scpk1Gt6iNhAEk4RMCVP%2FfVu51yHhsiQKTE9vQLqbuj_doc.png?alt=media&#x26;token=7d7ad100-20d0-4d2e-9cd8-5321b44535d0" alt=""><figcaption></figcaption></figure>

#### 8. Remplir "Sélectionnez le pays Bénin Burkina-Faso Côte d'Ivoire Sénégal Togo"

Renseignez le champ avec le pays sélectionné

<figure><img src="https://static.guidde.com/v0/qg%2FpOO86wzsXKMLqRP4iQ5el5UNXkR2%2Fx9scpk1Gt6iNhAEk4RMCVP%2Fw2myaVC1X2wDdcvcSAYEzs_doc.png?alt=media&#x26;token=dac7e441-d252-4e63-854a-c473e1182c33" alt=""><figcaption></figcaption></figure>

#### 9. Cliquez "Sélectionnez le réseau mobile MOOV MTN"

Choisissez le réseau mobile parmi les options disponibles

<figure><img src="https://static.guidde.com/v0/qg%2FpOO86wzsXKMLqRP4iQ5el5UNXkR2%2Fx9scpk1Gt6iNhAEk4RMCVP%2Fr6fajALVA1MH9fjJ1pKgEr_doc.png?alt=media&#x26;token=0bd4fefe-75ef-4391-abb3-3634063012d5" alt=""><figcaption></figcaption></figure>

#### 10. Remplir "Sélectionnez le réseau mobile MOOV MTN"

Entrez le réseau mobile sélectionné

<figure><img src="https://static.guidde.com/v0/qg%2FpOO86wzsXKMLqRP4iQ5el5UNXkR2%2Fx9scpk1Gt6iNhAEk4RMCVP%2F2FMikvQYT25tEENLe62WqK_doc.png?alt=media&#x26;token=878e83e0-33c5-41bd-8ee9-59983431a416" alt=""><figcaption></figcaption></figure>

#### 11. Cliquez "John Doe"

Entrez votre nom complet

<figure><img src="https://static.guidde.com/v0/qg%2FpOO86wzsXKMLqRP4iQ5el5UNXkR2%2Fx9scpk1Gt6iNhAEk4RMCVP%2F6oYCH7idEDFBELJcPYg7EX_doc.png?alt=media&#x26;token=4b311728-908d-4a1d-a216-ebac8ca9dbd6" alt=""><figcaption></figcaption></figure>

#### 12. Cliquez "example@gmail.com"

Entrez votre adresse email

<figure><img src="https://static.guidde.com/v0/qg%2FpOO86wzsXKMLqRP4iQ5el5UNXkR2%2Fx9scpk1Gt6iNhAEk4RMCVP%2FhSPntgdcSZuUEsDsSszVfA_doc.png?alt=media&#x26;token=fd07e1ed-6cbc-4879-a5f8-cc77b798d1af" alt=""><figcaption></figcaption></figure>

#### 13. Cliquez "Payer 1000 XOF"

Appuyez sur "Payer"

#### 14. Cliquez "Extensions"

Accédez à l'onglet "Extensions" pour pouvoir ajouter une extension nécessaire mais pas disponible dans votre plan actuel

<figure><img src="https://static.guidde.com/v0/qg%2FpOO86wzsXKMLqRP4iQ5el5UNXkR2%2Fx9scpk1Gt6iNhAEk4RMCVP%2Fm69BVfJ5b6w9LDp5puiiEx_doc.png?alt=media&#x26;token=061fc033-71bc-4020-9a08-ead9876fd976" alt=""><figcaption></figcaption></figure>

Ce guide vous a aidé à gérer les abonnements sur Edueasy en suivant des instructions précises. Vous avez pu mettre à jour les plans, effectuer des paiements, et remplir les informations nécessaires pour gérer les abonnements avec succès.
