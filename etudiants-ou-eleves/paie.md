# Paie

#### 1. Cliquez sur [Gérer la paie](https://edueasy.net/payroll)

Accédez à la section **"Gérer la paie"** pour consulter et gérer les informations relatives aux salaires des enseignants. Vous pouvez y trouver toutes les options nécessaires pour le traitement des paiements.

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/d883e906-2c64-499d-a26c-3cf8db0f9de1/1/3.1323414252153/66.051630434783?0)

#### 2. Cliquez sur le mois que vous voulez

Sélectionnez le mois pour lequel vous souhaitez gérer les salaires. Cette étape est cruciale pour vous assurer que vous travaillez sur la période correcte.

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/6ad076a2-41c5-4b5d-b40f-0bb4b76a013a/1/26.62490211433/41.945652173913?0)

#### 3. Cliquez sur Sélectionner Année \*

Choisissez l'année correspondante pour filtrer les informations de paie. Ce champ est obligatoire pour une gestion correcte des salaires.

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/b23af0d6-8f52-46de-a619-0116cfa08723/1/52.182850430697/37.771739130435?0)

#### 4. Cliquez sur Rechercher

Lancez la recherche pour afficher les informations de paie correspondant aux critères que vous avez sélectionnés. Cette étape permet d'afficher les données pertinentes pour le mois et l'année choisis.

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/8ab1dd06-c4c4-4fa3-8758-dd4432107c77/1/74.065803641347/41.945652173913?0)

#### 5. Tapez le salaire net de vos enseignants

Entrez le montant net du salaire pour chaque enseignant. Assurez-vous de fournir des montants précis pour garantir le bon traitement des paiements.

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/6ebd5322-18fa-49d6-bafa-f215b02aa4ca/1/89.538469068128/50.048913043478?0)

#### 6. Cliquez sur Soumettre

Finalisez le processus en cliquant sur **"Soumettre"**. Cette action enregistre les informations de paie que vous avez entrées et les rend actives.

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/02d6304d-46a0-425a-924b-793377b89a63/1/96.867658574785/94.048913043478?0)

### Comment ajouter des paramètres qui s'appliquent facilement à vos enseignants

#### 7. Cliquez sur [Paramètres de Paie](https://edueasy.net/payroll-setting)

Accédez à la section **"Paramètres de Paie"** pour configurer les différents paramètres qui influencent les calculs de paie pour vos enseignants.

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/7728af4c-8afd-4c43-bd35-0b434eedfdbf/1/3.1323414252153/33.35597826087?0)

#### 8. Cliquez sur Type \*

Sélectionnez le type de paramètre que vous souhaitez ajouter. Ce champ est essentiel pour définir la nature des paramètres de paie.

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/07ea547b-8188-499d-a759-f658c2a88eae/1/60.963194988254/47.336956521739?0)

#### 9. Cliquez sur Nom \*

Entrez le nom du paramètre de paie. Ce champ est requis pour identifier et distinguer les différents paramètres.

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/a438cdca-d4ce-480d-867e-5a2b1dda06de/1/60.963194988254/50.815217391304?0)

#### 10. Cliquez sur Montant fixe

Définissez un montant fixe si le paramètre de paie est basé sur un montant spécifique, indépendamment des autres variables.

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/2df08db0-41e7-4452-af73-68d2a2984a20/1/43.40250587314/71.858695652174?0)

#### 11. Cliquez sur Pourcentage

Si le paramètre de paie est basé sur un pourcentage, entrez le pourcentage approprié pour le calcul des salaires.

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/37e9e771-2e56-4a48-a43d-3e9b31e019fa/1/96.084573218481/71.858695652174?0)

#### 12. Cliquez sur Soumettre

Enregistrez les nouveaux paramètres en cliquant sur **"Soumettre"**. Assurez-vous que toutes les informations sont correctes avant de finaliser.

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/77648963-9a6d-42eb-95cb-e64522aaf150/1/95.301487862177/87.423913043478?0)
