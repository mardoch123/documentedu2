# Gestion du Personnel

***

## Créer le rôle qu'il faut

Pour gérer les accès et permissions au sein de votre établissement, suivez les étapes ci-dessous pour créer des rôles sur EDUEASY.

#### 1. Accédez à la section Gestion des rôles

Commencez par aller sur la page **Gestion des rôles** de EDUEASY pour configurer ou modifier les rôles existants.

![](https://dubble-prod-01.s3.amazonaws.com/assets/f57f9a21-fd50-4998-9905-c691a001f55b.png?0)

#### 2. Cliquez sur Créer un nouveau rôle

Pour ajouter un nouveau rôle, cliquez sur **Créer un nouveau rôle**.

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/d4465c96-1c46-463a-bd8e-6112cfee0cc8/1/98.433829287392/17.04347826087?0)

#### 3. Entrez le nom du rôle

Donnez un nom au rôle, par exemple **Comptable**, en cliquant sur **Nom \***.

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/3aab5ffb-34b3-46bf-aca6-d248f44611c9/1/60.963194988254/37.494565217391?0)

#### 4. Choisissez les permissions

Sélectionnez les permissions à attribuer à ce rôle dans la section **Permissions**.

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/37a3306b-9004-42c8-b545-9474d94a65fe/1/60.963194988254/521.14673913043?0)

#### 5. Cliquez sur Soumettre

Après avoir défini le rôle et ses permissions, cliquez sur **Soumettre** pour enregistrer.

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/902fa2b0-3c21-47b8-a4c2-14308e9f2bd4/1/96.084573218481/67.755434782609?0)

#### 6. Cliquez sur Retour

Pour revenir à la liste des rôles, cliquez sur **Retour**.

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/55f5d939-8423-4eee-9c94-0e6dec407aa3/1/95.301487862177/31.929347826087?0)

## Ajouter le personnel

#### 7. Cliquez sur Personnel dans le menu

Pour gérer le personnel, cliquez sur **Personnel** dans le menu.

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/62a76576-cabc-4640-9556-0affbc6f4938/1/3.1323414252153/37.766304347826?0)

#### 8. Remplissez le formulaire

Complétez le formulaire d'ajout de personnel avec les informations nécessaires.

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/8e0c27ea-712f-4c54-9a9b-0e310b60c73c/1/60.963194988254/109.05706521739?0)

#### 9. Sélectionnez le Type d'allocation

Choisissez le **Type d'allocation** approprié pour le personnel.

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/8a8b63f3-e307-4a81-9fb4-f05f91a2efd3/1/60.963194988254/47.45652173913?0)

#### 10. Sélectionnez le Type de déduction

Définissez le **Type de déduction** si nécessaire.

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/e58a620d-a006-45ae-ae86-e1280d9771f8/1/60.963194988254/71.576086956522?0)

#### 11. Cliquez sur Soumettre

Après avoir complété le formulaire, cliquez sur **Soumettre** pour ajouter le membre du personnel.

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/981719f2-6cbc-4f31-a570-fe08347aa3af/1/95.301487862177/15.75?0)

## Télécharger plusieurs membres du personnel en une seule fois

#### 12. Cliquez sur Téléchargement en masse

Pour ajouter plusieurs membres du personnel simultanément, utilisez l'option **Téléchargement en masse**.

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/260dc402-632a-45ee-a7a7-1678b27c024a/1/3.1323414252153/62.461956521739?0)

#### 13. Sélectionnez les Rôles

Lors du téléchargement en masse, assurez-vous de définir les rôles de chaque membre du personnel.

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/23a0ab0f-def3-47a3-bede-dbb480f7d3c5/1/60.963194988254/42.538043478261?0)

#### 14. Soumettez après avoir chargé le fichier

Une fois le fichier téléchargé et les rôles définis, cliquez sur **Soumettre**.

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/c08d7776-42a3-4edb-aa21-2764f959ae78/1/60.963194988254/52.182065217391?0)

Ce guide vous aide à créer et gérer les rôles ainsi qu'à ajouter le personnel sur EDUEASY de manière efficace.
