# Enseignants/Professeurs

#### **Onglet "Enseignants"**

L'onglet "Enseignants" offre plusieurs fonctionnalités pour la gestion complète des membres du corps enseignant dans votre établissement. Voici ce que vous pouvez faire dans cet onglet :

* **Créer un Enseignant** : Ajoutez de nouveaux enseignants en remplissant un formulaire détaillé. Ce formulaire vous permet de saisir des informations essentielles telles que le nom, le prénom, la date de naissance, le genre, le numéro de téléphone mobile, l'adresse e-mail, et la photo de l'enseignant si disponible. Vous pouvez également entrer des détails sur la qualification, l'adresse actuelle et permanente, le salaire, et le statut de l'enseignant.
* **Modifier un Enseignant** : Mettez à jour les informations des enseignants existants. Que ce soit pour corriger des informations, ajouter des détails manquants ou ajuster des données académiques, cette fonctionnalité vous permet de garder les profils des enseignants à jour.
* **Supprimer un Enseignant** : En cas de besoin, vous pouvez supprimer les profils des enseignants qui ne sont plus actifs dans l’établissement. Cette action permet de maintenir une base de données propre et pertinente.
* **Téléchargement en Masse** : Importez les données des enseignants en grande quantité en téléchargeant un fichier contenant les informations nécessaires. Vous pouvez obtenir un modèle de fichier à partir de l'option "Télécharger un fichier fictif" et remplir ce modèle avec les données des enseignants avant de le téléverser.
* **Télécharger** : Après avoir modifié le fichier modèle avec les informations des enseignants, cliquez sur "Télécharger" pour téléverser ce fichier dans le système. Assurez-vous que toutes les entrées respectent les exigences du format pour éviter les erreurs d'importation.

Ces fonctionnalités permettent une gestion efficace des enseignants, facilitant l’ajout, la mise à jour et la maintenance des informations académiques dans votre système.
