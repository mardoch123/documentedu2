# Comment ajouter un ensemble d'enseignant ?

#### 1. Cliquez sur "Téléchargement en masse"

Pour procéder à l'importation de données d'étudiants en grande quantité, cliquez sur l'option "**Téléchargement en masse**". Cette fonctionnalité vous permet de télécharger un fichier contenant les informations de plusieurs étudiants simultanément, facilitant ainsi l'ajout ou la mise à jour de nombreux profils à la fois. Vous pourrez généralement choisir un fichier au format CSV ou Excel contenant les données nécessaires, ce qui simplifie la gestion des inscriptions et des mises à jour dans votre système. Assurez-vous que le fichier respecte le format et les exigences spécifiées pour éviter les erreurs lors du téléchargement.

#### 2. Cliquez sur "Télécharger un fichier fictif"

Pour obtenir un modèle de fichier à utiliser pour le téléchargement en masse, cliquez sur **"Télécharger un fichier fictif"**. Ce fichier contient les colonnes et le format requis pour importer correctement les données des étudiants dans votre système. Assurez-vous de remplir ce fichier rigoureusement avec les informations nécessaires avant de le téléverser. Le respect précis du format et des instructions fournies est crucial pour éviter les erreurs lors de l'importation des données. Une fois le fichier complété, vous pourrez le téléverser pour ajouter ou mettre à jour les informations des étudiants en masse.

#### 3. Cliquez sur "Télécharger"

Pour enregistrer les informations modifiées, cliquez sur "Télécharger". Ce bouton vous permettra de téléverser le fichier que vous avez préalablement modifié avec les détails de l'ensemble des enseignants de votre école. Assurez-vous que toutes les entrées respectent le format et les instructions spécifiées dans le modèle de fichier pour garantir une importation correcte des données. Ce processus facilitera l'ajout ou la mise à jour des informations des enseignants dans votre système de gestion.
