# Comment ajouter un professeur dans votre école sur EDUEASY

### [# Enseignant || EDUEASY](https://edueasy.net/teachers)

#### 1. Cliquez sur "Gérer les enseignants"

Pour accéder à la gestion des enseignants, cliquez sur l'option "Gérer les enseignants". Cette section vous permettra d'ajouter, de modifier ou de supprimer des enseignants, ainsi que de gérer leurs informations et leurs affectations au sein de l'établissement. Vous pourrez également voir un aperçu des enseignants actuellement enregistrés et effectuer les ajustements nécessaires à leurs profils.

#### 2. Remplissez les champs suivants :

* **Nom** : Entrez le nom de l'enseignant.
* **Prénom** : Entrez le prénom de l'enseignant.
* **Date de naissance** : Saisissez la date de naissance de l'enseignant.
* **Genre** : Sélectionnez le genre de l'enseignant.
* **Mobile** : Entrez le numéro de téléphone mobile de l'enseignant.
* **E-mail** : Saisissez l'adresse e-mail de l'enseignant.
* **Photo (si possible)** : Téléchargez une photo de l'enseignant si disponible.
* **Qualification** : Indiquez la qualification de l'enseignant (par exemple, Docteur, Licencié en Mathématiques).
* **Adresse actuelle** : Entrez l'adresse actuelle de l'enseignant.
* **Adresse permanente** : Saisissez l'adresse permanente de l'enseignant.
* **Salaire** : Précisez le salaire de l'enseignant.
* **Statut** : Sélectionnez le statut de l'enseignant (par exemple, Actif, Inactif).

Ces informations sont essentielles pour assurer le bon fonctionnement de votre site web, permettant l'affichage détaillé des profils des enseignants et garantissant une gestion efficace des informations de votre personnel académique.

#### 3. Cliquez sur "Type d'allocation"

Pour spécifier le type d'allocation pour l'enseignant, cliquez sur le champ "Type d'allocation". Une liste d'options apparaîtra, vous permettant de choisir le type d'allocation approprié pour l'enseignant. Cela peut inclure des options telles que "Allocation fixe", "Allocation horaire", ou d'autres types en fonction des paramètres de votre système. Sélectionnez l'option qui correspond au mode de rémunération ou de compensation de l'enseignant.

#### 4. Cliquez sur "Type de déduction"

Pour spécifier le type de déduction applicable à l'enseignant, cliquez sur le champ "Type de déduction". Une liste d'options s'affichera, vous permettant de choisir le type de déduction approprié. Cela peut inclure des options telles que "Déduction fiscale", "Déduction pour absences", ou d'autres types selon les paramètres de votre système. Sélectionnez l'option qui correspond au type de déduction à appliquer sur le salaire de l'enseignant.
