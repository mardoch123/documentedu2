# Paramètres système

Pour le menu de paramétrage, voici un texte explicatif détaillé pour chaque section. Ce texte aidera les utilisateurs à comprendre clairement l'objectif de chaque lien et comment naviguer dans le menu. Les liens sont intégrés directement dans les descriptions pour une navigation facile.

## Menu Paramétrage

Le menu de paramétrage vous permet de gérer et configurer divers aspects de l'application selon vos besoins spécifiques. Voici une description détaillée de chaque option disponible :

* **Paramètres généraux**\
  [Accédez aux paramètres généraux](https://edueasy.net/school-settings) pour configurer les options de base de votre application, telles que le nom de l'école, le logo, les informations de contact et autres préférences de base. Ces paramètres affectent l'apparence et le fonctionnement global de la plateforme.



* **Année de session**\
  [Définissez l'année de session](https://edueasy.net/session-year) pour l'école afin de s'assurer que toutes les activités académiques sont alignées avec la bonne année scolaire. Cette section permet de mettre à jour et de gérer les années scolaires en cours et futures.



* **Congé Paramètres**\
  [Gérez les paramètres de congé](https://edueasy.net/leave-master) pour configurer les types de congés disponibles pour les étudiants et le personnel, ainsi que les règles et politiques associées. Cela inclut la gestion des jours fériés, des absences justifiées, et des congés spéciaux.



* **Termes et conditions des examens en ligne**\
  [Consultez les termes et conditions des examens en ligne](https://edueasy.net/school-settings/online-exam) pour définir les règles que les étudiants doivent suivre lors des examens en ligne. Cette section est essentielle pour s'assurer que les examens sont conduits de manière équitable et conformément aux règles établies.



* **Modèle d'Email**\
  [Accédez aux modèles d'email](https://edueasy.net/school-settings/email-template) pour personnaliser les communications par courriel envoyées depuis l'application. Vous pouvez modifier les messages d'accueil, les notifications de paiement, les rappels de devoirs, et plus encore pour qu'ils reflètent le ton et le style de votre établissement.



* **Paramètres de paiement**\
  [Configurez les paramètres de paiement](https://edueasy.net/system-settings/payment) pour gérer les options de paiement disponibles pour les frais de scolarité, les activités extra-scolaires et autres services payants. Vous pouvez définir les méthodes de paiement, les devises acceptées, et d'autres options de facturation.



* **Conditions générales**\
  [Consultez et modifiez les conditions générales](https://edueasy.net/school-settings/terms-condition) qui régissent l'utilisation de l'application par les étudiants, le personnel, et les parents. Assurez-vous que ces conditions sont claires, à jour et bien communiquées à tous les utilisateurs.



* **Politique de confidentialité**\
  [Consultez la politique de confidentialité](https://edueasy.net/school-settings/privacy-pilicy) pour comprendre comment les données personnelles des utilisateurs sont collectées, utilisées et protégées. Assurez-vous que la politique respecte les lois en vigueur et qu'elle est facilement accessible aux utilisateurs pour leur transparence et leur tranquillité d'esprit.

Ces liens vous redirigeront directement vers les sections correspondantes pour une configuration facile et rapide de votre application. Assurez-vous de vérifier régulièrement ces paramètres pour qu'ils soient toujours à jour et conformes aux besoins de votre école ou institution.
