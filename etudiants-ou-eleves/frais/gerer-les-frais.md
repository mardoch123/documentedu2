# Gérer les frais

***

#### [1. Cliquez sur Gérer les frais](https://edueasy.net/fees-type)

Accédez à cette option pour commencer à gérer les différents types de frais dans votre système. Cette étape vous permet de configurer et de suivre les frais applicables aux étudiants.

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/1d4b2039-8dba-44f7-9a0d-c8a58f7019a3/1/3.1323414252153/31.964673913043?0)

#### [2. Cliquez sur Nom de préfixe \*](https://edueasy.net/fees)

Entrez un nom descriptif pour le type de frais que vous souhaitez créer. Ce nom aide à identifier et à classer les frais de manière claire.

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/16d2941d-1ec9-4211-b005-843fe8ca3fe7/1/44.146436961629/53.864809782609?0)

#### [3. Cliquez sur Classes pour sélectionner les classes concernées \*](https://edueasy.net/fees)

Sélectionnez les classes auxquelles ce type de frais s'applique. Cette étape garantit que les frais sont attribués aux bonnes sections.

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/adde8a62-f76c-429c-bf79-9749c1f79a71/1/94.596711041504/53.864809782609?0)

#### [4. Cliquez sur Sélectionner un type de frais](https://edueasy.net/fees)

Choisissez le type de frais que vous souhaitez appliquer à partir des options disponibles. Cela permet de spécifier exactement quel frais vous configurez.

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/774447e6-1d98-46b5-95dd-4a2d9b798256/1/28.112764291308/40.148097826087?0)

#### [5. Entrez le montant des frais](https://edueasy.net/fees)

Indiquez le montant spécifique des frais. Cette information est cruciale pour le calcul des paiements que les étudiants doivent effectuer.

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/307b95ef-f5ab-4a65-babe-4a79eff4ec22/1/64.871892129992/40.148097826087?0)

#### [6. Entrez une date d'échéance](https://edueasy.net/fees)

Définissez la date limite à laquelle les frais doivent être payés. Cette étape aide à gérer les délais et à s'assurer que les paiements sont effectués à temps.

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/c1fcd540-2f1a-416b-b415-35787d845ffc/1/28.112764291308/48.669836956522?0)

#### [7. Entrez en pourcentage combien les gens doivent payer sur le coup](https://edueasy.net/fees)

Indiquez le pourcentage du montant total des frais que les étudiants doivent payer immédiatement. Cela permet de gérer les paiements échelonnés ou partiels.

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/d5569898-3fc2-4c96-80c6-4ac67524b23c/1/52.554815974941/48.669836956522?0)

#### [8. Ceci est calculé automatiquement quand vous entrez le pourcentage dû](https://edueasy.net/fees)

Le montant à payer immédiatement est calculé automatiquement en fonction du pourcentage que vous avez saisi, facilitant ainsi la gestion des paiements.

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/a48310b6-095b-47ba-8028-c4ed95515ea4/1/76.996867658575/48.669836956522?0)

#### [9. Choisissez si vous voulez que le paiement soit activé automatiquement ou non](https://edueasy.net/fees)

Déterminez si le paiement doit être déclenché automatiquement ou si vous préférez le faire manuellement. Cette option offre une flexibilité dans la gestion des paiements.

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/dbaef071-feb8-4943-91e5-9eaeb1ea8ff7/1/61.746280344558/54.460597826087?0)

#### [10. Cliquez pour ajouter des frais additionnels](https://edueasy.net/fees)

Ajoutez des frais supplémentaires si nécessaire en utilisant cette option. Cela vous permet de gérer des coûts divers associés aux frais principaux.

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/5a1a867a-edf7-482a-b5e5-de46d0e9df00/1/61.746280344558/62.389945652174?0)

#### [11. Cliquez sur Soumettre](https://edueasy.net/fees)

Finalisez la configuration en soumettant vos informations. Assurez-vous que tous les détails sont corrects avant de valider.

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/ccbecd43-61e2-4a7b-8652-c8216c9e867a/1/96.867658574785/90.267663043478?0)
