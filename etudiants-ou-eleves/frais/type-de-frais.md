#### [1. Allez à "Type de frais"](https://edueasy.net/fees-type)

Cette section vous permet de définir les différents types de frais applicables dans votre établissement de manière simple et efficace. En accédant à "Type de frais", vous pouvez :

* **Créer de nouveaux types de frais** : Ajoutez des catégories de frais spécifiques telles que les frais de scolarité, les frais d'examen, les frais de matériel, etc.

Définir les types de frais vous permet de structurer les coûts de manière claire et organisée, facilitant ainsi la gestion financière et la communication avec les étudiants et les parents. Cela assure également que tous les frais sont correctement classifiés et suivis dans votre système.

![](https://dubble-prod-01.s3.amazonaws.com/assets/f23a91d1-2e13-45ca-9d03-92f2d6a5ae7b.png?0)

#### [2. Cliquez sur "Nom" pour entrer le nom du type de frais](https://edueasy.net/fees-type)

En cliquant sur "Nom", vous pouvez entrer le nom spécifique du type de frais que vous souhaitez définir. Ce champ est essentiel pour identifier clairement chaque catégorie de frais dans votre système. Voici ce que vous devez faire :

* **Entrez le nom du type de frais** : Par exemple, vous pourriez entrer des noms comme "Frais de scolarité", "Frais d'examen", ou "Frais de matériel scolaire".
* **Soyez précis et descriptif** : Assurez-vous que le nom reflète clairement le type de frais pour éviter toute confusion.

Définir correctement le nom du type de frais est crucial pour garantir que les frais sont correctement classifiés et facilement identifiables dans vos rapports financiers et votre gestion quotidienne.
