# Transfert de Section de Classe et Transfert de Session Scolaire dans EDUEASY

### [# Transfert de Section de Classe et Transfert de Session Scolaire dans EDUEASY](https://edueasy.net/class-section)

Dans EDUEASY, vous pouvez gérer deux types de transferts :

1. **Transfert d'une Section de Classe à une Autre**
   * **Description** : Ce transfert concerne le déplacement d'un groupe d'élèves d'une section spécifique à une autre au sein de la même année scolaire ou programme. Par exemple, les élèves d'une section "A" pourraient être transférés à la section "B".
   * **Utilité** : Cette fonctionnalité est utile pour réorganiser les groupes en fonction des besoins pédagogiques ou des changements dans la composition des classes.
2. **Transfert d'une Session Scolaire à une Autre**
   * **Description** : Ce transfert concerne le passage des élèves d'une session scolaire à une autre, généralement d'une année à la suivante. Par exemple, les élèves de la session "2023-2024" passent à la session "2024-2025".
   * **Utilité** : Ce type de transfert est essentiel pour mettre à jour les informations académiques des élèves lorsqu'ils avancent d'une année scolaire à une autre, permettant de maintenir des dossiers précis et à jour.

Ces fonctionnalités assurent une gestion fluide et organisée des mouvements académiques au sein de l’établissement.

#### 1. Cliquez sur "Transférer les étudiants"

Pour initier le transfert des étudiants, cliquez sur le bouton **"Transférer les étudiants"**. Cette action vous dirigera vers l'interface où vous pourrez choisir le type de transfert à effectuer : soit d'une section de classe à une autre, soit d'une session scolaire à une autre. Suivez les instructions à l'écran pour sélectionner les étudiants concernés, spécifier la nouvelle section ou session, et confirmer le transfert. Ce processus permet de réorganiser efficacement les groupes d'élèves en fonction des besoins académiques ou administratifs.

#### 2. Sélectionnez une section de classe depuis "Section de classe actuelle"

Pour transférer les étudiants, choisissez d'abord une section de classe actuelle dans le champ **"Section de classe actuelle"**. Cette sélection vous permettra de spécifier la section d'origine des étudiants que vous souhaitez transférer. Assurez-vous de sélectionner la section correcte pour garantir que les étudiants seront déplacés depuis la bonne classe.

#### 3. Sélectionnez la section de classe depuis "Transférer à la section de classe"

Pour compléter le transfert des étudiants, choisissez la section de classe dans laquelle vous souhaitez les transférer depuis le champ "Transférer à la section de classe". Cette sélection déterminera la nouvelle section où les étudiants seront déplacés. Assurez-vous de choisir la section cible appropriée pour que les étudiants soient correctement réaffectés.

#### 4. Sélectionnez les étudiants que vous souhaitez transférer

Dans l'interface de transfert, choisissez les étudiants (ou "appartenants") que vous souhaitez déplacer de la section actuelle vers la nouvelle section. Vous pouvez généralement sélectionner les étudiants individuellement ou en groupe, selon les options disponibles. Assurez-vous que tous les étudiants que vous souhaitez transférer sont correctement sélectionnés avant de procéder à la confirmation du transfert.

#### 6. Sélectionnez la section de classe depuis "Section de classe"

Pour effectuer le transfert, choisissez la section de classe dans le champ "Section de classe". Ce champ vous permet de spécifier la section actuelle des étudiants que vous souhaitez transférer. Assurez-vous de sélectionner la section correcte pour garantir que le transfert se fait depuis la bonne classe.

#### 7. Sélectionnez la session d'année depuis "Transférer en"

Pour compléter le transfert, choisissez la session d'année dans le champ "Transférer en". Ce champ vous permet de spécifier la session scolaire ou l'année académique vers laquelle les étudiants seront transférés. Assurez-vous de sélectionner la session correcte pour garantir que les étudiants sont déplacés vers la période académique appropriée.

Pour finaliser le transfert, choisissez la classe dans le champ "Transférer dans la classe". Ce champ vous permet de spécifier la nouvelle classe où les étudiants seront déplacés. Assurez-vous de sélectionner la classe appropriée pour garantir que les étudiants sont correctement réaffectés à leur nouvelle classe.
