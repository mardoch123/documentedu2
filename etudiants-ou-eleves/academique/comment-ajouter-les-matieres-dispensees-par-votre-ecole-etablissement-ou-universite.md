# Comment ajouter les matières dispensées par votre école, établissement ou université

Pour ajouter les matières dispensées par votre institution dans EDUEASY, suivez ces étapes :

1. **Accédez à l'onglet "**[**Académiques**](/broken/pages/QfwWRFAR4fp2jSSobmPl)**"** :
   * Connectez-vous à votre compte sur la plateforme EDUEASY.
   * Cliquez sur l'onglet "Académiques" pour accéder à la gestion des ressources pédagogiques.
2. **Cliquez sur "**[**Matières**](/broken/pages/QfwWRFAR4fp2jSSobmPl)**"** 😀
   * Dans la section académique, sélectionnez l'option "Matières" pour gérer les matières proposées.
3. **Choisissez la langue du cours** :
   * Sélectionnez la langue dans laquelle la matière sera dispensée. Assurez-vous que la langue choisie correspond à celle définie précédemment pour garantir la cohérence.
4. **Entrez le nom de la matière** :
   * Saisissez le nom de la matière (par exemple, "Mathématique") dans le champ prévu. Ce nom doit refléter le sujet d'étude de manière claire et précise.
5. **Entrez le code du sujet** :
   * Fournissez un code unique pour la matière (par exemple, "Math") qui facilitera son identification dans l'application.
6. **Choisissez une couleur** :
   * Sélectionnez une couleur pour représenter visuellement la matière dans la plateforme. Cette couleur aidera à différencier les matières et à améliorer la navigation.
7. **Choisissez une image** :
   * Téléchargez ou sélectionnez une image représentative de la matière. Cette image sera utilisée pour une identification visuelle claire dans l'application.
8. **Cliquez sur "Soumettre"** :
   * Finalisez l'ajout de la matière en cliquant sur le bouton "Soumettre". Cette action enregistrera toutes les informations que vous avez fournies et intégrera la matière dans le système.

En suivant ces étapes, vous pouvez ajouter efficacement les matières dispensées par votre institution, en veillant à ce que toutes les ressources pédagogiques soient bien organisées et accessibles pour les utilisateurs.
