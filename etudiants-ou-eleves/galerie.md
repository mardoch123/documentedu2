# Galerie

***

#### 1. Cliquez sur Galerie

Accédez à la section **"Galerie"** pour gérer les images et les vidéos. Cette option vous permet de créer et de gérer des galeries multimédia sur votre plateforme. Cliquez sur le lien [ici](https://edueasy.net/gallery) pour ouvrir la page appropriée.

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/34f7b721-3f61-45fb-9d9a-a85cb11ae5ae/1/4.3069694596711/67.561141304348?0)

#### 2. Cliquez sur Titre \*

Pour chaque élément de la galerie, entrez un **titre** dans le champ prévu à cet effet. Le titre est un champ obligatoire (\*) et permet d'identifier facilement chaque image ou vidéo dans votre galerie. Ce champ est essentiel pour organiser vos contenus.

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/2888574e-6573-454e-8b8c-8a1f093bed04/1/43.40250587314/47.691576086957?0)

#### 3. Cliquez sur Description (Optionnel)

Ajoutez une **description** si vous souhaitez fournir des détails supplémentaires sur l'image ou la vidéo. Bien que ce champ soit optionnel, il peut être utile pour donner plus de contexte ou d'explications sur le contenu.

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/5ac5edbf-8160-4848-b59f-887173d30934/1/96.084573218481/47.691576086957?0)

#### 4. Cliquez sur Vignette \* ( jpg, svg, jpeg, png )

Téléchargez une **vignette** pour chaque image ou vidéo. Les formats acceptés sont jpg, svg, jpeg, et png. Cette vignette sera utilisée comme image de prévisualisation pour l'élément dans la galerie. Ce champ est obligatoire (\*) pour chaque ajout de contenu.

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/09dd8faf-5053-4da4-a258-dc430c8db59e/1/43.40250587314/69.785326086957?0)

#### 5. Cliquez sur Images (Télécharger plusieurs images) Optionnel

Si vous souhaitez ajouter plusieurs images à la fois, vous pouvez les télécharger en une seule fois en utilisant cette option. Ce champ est optionnel et permet de gagner du temps lors du téléchargement de multiples fichiers multimédia.

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/656a1825-144d-4d49-a4d0-6b6a7e3799c5/1/96.084573218481/69.785326086957?0)

#### 6. Cliquez sur Liens YouTube (Veuillez utiliser des virgules ou appuyer sur Entrée pour ajouter plusieurs liens.) Optionnel

Vous pouvez ajouter des **liens YouTube** si vous souhaitez intégrer des vidéos dans la galerie. Utilisez des virgules ou appuyez sur Entrée pour ajouter plusieurs liens. Ce champ est optionnel et permet d'enrichir la galerie avec des contenus vidéo externes.

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/b46e95dd-b573-478b-8c2c-93f329ddeb12/1/43.40250587314/86.828804347826?0)

#### 7. Cliquez sur Année de session

Sélectionnez l'**année de session** pour classer vos images et vidéos en fonction de l'année. Cette option vous permet de mieux organiser vos contenus selon les périodes spécifiques de votre activité.

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/c324208d-b0ee-472a-8cdd-eb4b4f42171d/1/78.523884103367/86.828804347826?0)

#### 8. Cliquez sur Soumettre

Finalisez l'ajout de vos images, vidéos, et paramètres en cliquant sur **"Soumettre"**. Cette action enregistre toutes les informations que vous avez entrées et les rend disponibles dans votre galerie.

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/5b02abdb-c31e-4d1f-ba5d-1be37925943b/1/95.301487862177/68.220108695652?0)
