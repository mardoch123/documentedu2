# Certificat du personnel

***

#### 1. Cliquez sur Certificat étudiant

Pour commencer, accédez à la page des certificats en cliquant sur **"Certificat étudiant"** sur le site d'EDUEASY. Cela vous mènera à l'interface où vous pouvez sélectionner et gérer les certificats pour les étudiants.

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/980e56eb-b6e9-4764-ba82-cdbe321743d8/1.5/3.1323414252153/40.201086956522?0)

#### 2. Cliquez sur Certificat Modèle

Une fois sur la page des certificats, sélectionnez le **"Certificat Modèle"** qui correspond à vos besoins. Cette étape vous permet de choisir le format et le style du certificat que vous allez attribuer aux étudiants.

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/9c9f1f03-a8b2-4973-bc2c-5e803555e139/2.5/26.62490211433/37.076086956522?0)

#### 3. Cliquez sur Section de classe (optionnel mais important)

Pour filtrer plus précisément les étudiants à qui vous souhaitez attribuer des certificats, cliquez sur **"Section de classe"**. Bien que cette étape soit optionnelle, elle est recommandée pour une meilleure organisation.

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/e8376c53-ec6d-4fbb-98dc-28ec895bc026/1/26.62490211433/53.597826086957?0)

#### 4. Cliquez sur Année de session (optionnel mais important)

De même, vous pouvez spécifier l'**"Année de session"** pour affiner davantage votre sélection. Cette étape optionnelle aide à filtrer les étudiants en fonction de leur année d'inscription ou de session.

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/f8a7fe92-0ddc-45f4-8561-859a29b4b4b4/1/45.85760082224/49.336956521739?0)

#### 5. Cochez les étudiants ou élèves pour lesquels vous voulez attribuer le certificat sélectionné

Cochez les cases à côté des noms des étudiants auxquels vous souhaitez attribuer le certificat. Cette étape permet de sélectionner un ou plusieurs étudiants pour générer le certificat en fonction des critères définis.

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/2f091a7a-5a7f-4a30-ab31-d103896e7998/1/27.956147220047/65.423913043478?0)

#### 6. Cliquez sur Générer

Après avoir sélectionné les étudiants et les options de filtrage, cliquez sur **"Générer"** pour créer les certificats. Cette action génère automatiquement les certificats basés sur les modèles et informations fournies.

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/30cac865-446f-4d5c-a6c7-4c41fce91e75/1/96.084573218481/95.858695652174?0)

#### 7. Vous serez redirigé vers la page des certificats en format PDF

Enfin, une fois les certificats générés, vous serez redirigé vers une page où vous pourrez visualiser les certificats en **format PDF**. À partir de cette page, vous pouvez soit imprimer les certificats, soit les partager sous forme de PDF directement avec les étudiants.

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/6d5a892d-189a-4504-9bda-5a7ccf789f18/1/96.084573218481/73.684782608696?0)
