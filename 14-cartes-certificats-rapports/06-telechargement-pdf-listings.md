# 📥 Téléchargement PDF des listes officielles

## 🎯 Rôle
En plus des rapports interactifs (*05*), l'école doit fournir des **documents papier signés**
à l'administration (inspection, mairie, concours) : **listes nominatives d'élèves**,
**feuilles de pointage**, **liste de présence d'examen**, **bordereaux**. Ce module produit
ces **listes au format PDF**, prêtes à **imprimer, signer et cacheter**.

## ✅ Prérequis
1. Données saisies : **élèves inscrits**, **examens créés**, **présences pointées**.
2. Permissions de consultation des listes concernées.
3. Une **imprimante** (ou l'usage d'Adobe/aperçu pour imprimer le PDF).

## 🟢 Télécharger une liste (étape par étape)
1. Depuis la **liste** concernée (élèves, examen, présences…), repérez le **bouton d'export
   PDF / Download** (souvent en haut du tableau, icône **PDF** ou **Imprimer**).
   Les mêmes boutons existent dans **Reports** (*05*) pour chaque rapport.
2. Le cas échéant, **choisissez les options** (classe, section, examen, période).
3. Le **PDF s'ouvre ou se télécharge** : nommez-le clairement
   (ex. `Liste_Cm2A_Sept2026.pdf`) et **rangez-le** dans un dossier par année.

## 🖨️ Imprimer pour signature
1. Ouvrez le PDF → **Imprimer** (mise en page **portrait A4**, marges par défaut).
2. **Signez et datez** à l'encre + **cachet** de l'établissement si exigé.

## ✏️ Modifier / 🔴 Supprimer / ♻️ Restaurer
- Un PDF téléchargé est un **fichier hors système** : il se **modifie en régénérant** la liste
  après correction des données, et se **supprime/range** comme tout fichier de votre
  ordinateur (corbeille de Windows).
- ⚠️ Le système ne **conserve pas** les PDF générés : si vous l'avez perdu,
  **relancez le téléchargement**.

## ⚠️ Bon à savoir
- **Régénérez toujours après correction** : une liste produite avant correction d'une note
  ou d'une absence reste **fausse** — imprimez la **dernière version**.
- **Versionnage** : ajoutez la **date** au nom du fichier pour éviter les confusions
  entre listes.
- **Listes officielles** : pour les documents exigés par le **ministère**, préférez le module
  **Rapports Ministériels & EducMaster** (PARTIE Académique) qui applique les **formats
  réglementaires**.
- **Feuilles de présence d'examen** : générables depuis le module **Examens** avant le
  début de l'épreuve.
