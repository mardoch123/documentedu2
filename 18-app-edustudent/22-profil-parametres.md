# ⚙️ 18.22 — EduStudent : profil, paramètres et se déconnecter

## 🎯 Rôle
L'écran **« Profil »** montre votre fiche (photo, nom, classe ou statut
parent) et le menu **« Paramètres »** regroupe les réglages du compte :
historique des paiements, mot de passe, notifications, documents légaux,
contact de l'éditeur et **déconnexion**.

## ✅ Prérequis
1. Être connecté (page 18.1).
2. Rien d'autre : ces écrans fonctionnent même si l'école n'a rien publié.

## 🟢 Voir et modifier son profil (étape par étape)
1. Onglet/bouton **« Profil »** (en bas ou dans le menu).
2. La fiche affiche : **photo**, **nom complet**, et selon le compte —
   la **classe** de l'élève, ou le profil **parent** (téléphone, e-mail).
3. Pour changer sa **photo** ou ses coordonnées : touchez le champ concerné
   (bouton d'édition), modifiez, **Enregistrez**.
4. L'élève **ne peut pas** changer sa classe, son nom ou son matricule :
   ces informations appartiennent à l'école (elle les corrige sur le web,
   PARTIE 06).
5. Le parent corrige **son propre** téléphone/e-mail ici ; pour que l'enfant
   soit rattaché au nouveau numéro, l'école doit mettre à jour la fiche élève.

## 🟢 Les Paramètres, ligne par ligne
Dans **« Paramètres »** :
1. **« Transactions »** : l'historique de **vos paiements** (frais, cantine,
   boutique) — montants, dates et moyens ; les reçus s'ouvrent ici
   (et via « Mes reçus »).
2. **« Changer mdp »** : modifier son mot de passe (l'ancien pour vérifier,
   le nouveau deux fois). En cas d'**oubli** : le mot de passe initial est la
   **date de naissance** — après l'avoir changé, seul le support de l'école
   peut le réinitialiser.
3. **« Notifications »** : régler la réception des alertes (devoirs, annonces,
   résultats).
4. **« Confidentialité »** : la politique de protection des données.
5. **« Règlement intérieur »** et **« Conditions »** : les documents officiels
   (identiques aux pages 18.21).
6. **« À propos »**, **« Contact »** : l'éditeur de l'application et ses
   coordonnées.
7. **« Noter »** : laisser une note sur le Store ; **« Partager »** : inviter
   d'autres parents par le partage du lien.
8. **« Version app »** : le numéro de version installé — à citer dans un
   signalement de bug.

## 🟢 Ouvrir un document (visionneuse)
1. Partout dans l'app (reçu, bulletin, cahier de vacances, annonce avec
   pièce jointe), un fichier s'ouvre dans la **visionneuse** : PDF feuilletable
   ou image agrandie.
2. Bouton de **partage** en haut : envoyer le fichier par WhatsApp, e-mail, ou
   l'**enregistrer** dans le téléphone pour l'imprimer plus tard.

## 🟢 Se déconnecter
1. Bouton **« Se déconnecter »** (bas des Paramètres).
2. Confirmer : la session est fermée sur **ce téléphone**.
3. Pour revenir : reconnexion normale — élève avec le **GR** + date de
   naissance (ou mot de passe changé), parent avec le **téléphone** (page 18.1).

## ✏️ Modifier
- Modifiables par vous : **photo, mot de passe, réglages de notifications,
  coordonnées du parent**.
- Non modifiables (école seule) : nom de l'élève, classe, matricule/GR,
  historique des transactions et des reçus.

## 🔴 Supprimer
- **Supprimer le compte** : possible uniquement en écrivant à l'école (et à
  l'éditeur) — l'app ne propose pas de bouton, car les données scolaires
  appartiennent à l'école et à l'élève (dossier).
- Se déconnecter **ne supprime rien**.
- Les transactions/reçus ne se suppriment pas côté app.

## ♻️ Restaurer
- Mot de passe oublié : utilisez le flux **« mot de passe oublié »** à la
  connexion (vérification par e-mail/téléphone, page 18.1), sinon demandez à
  l'école.
- Photo « effacée » après déconnexion : elle est en cache local — rechargez-la
  simplement.
- Notifications bloquées : vérifiez d'abord l'autorisation **Android/iOS**
  (Réglages du téléphone > Notifications > EduStudent), puis la ligne
  « Notifications » de l'app.
- Application qui rame après des mois : videz le cache ou
  **désinstallez/réinstallez** — la reconnexion restaure tout (les données
  sont sur les serveurs de l'école).

## ⚠️ Bon à savoir
- Notez votre **nouveau mot de passe** quelque part de sûr : la date de
  naissance, c'était le mot de passe **initial**, pas un moyen de récupération.
- L'historique **« Transactions »** est votre preuve comptable familiale :
  téléchargez les reçus des frais importants (inscriptions, examens).
- Deux téléphones peuvent utiliser le **même compte parent** simultanément :
  pratique pour le père et la mère.
- « Version app » + capture d'écran de l'erreur = le dossier complet à envoyer
  au support de l'école en cas de bug.
