# 👨‍👩‍👧 18.3 — EduStudent : l'espace parent (suivre tous ses enfants)

## 🎯 Rôle
Le parent connecté voit la **scolarité de chacun de ses enfants** : avis, présence,
notes, devoirs, frais, santé, transport — avec une **sélection d'enfant** qui bascule
tout l'espace sur le bon profil.

## ✅ Prérequis
1. Être connecté via **« Connexion Parent »** (page 18.1).
2. Que la fiche de chaque enfant mentionne **ce parent** (lien fait à l'admission,
   PARTIE 06). Sans lien, l'enfant n'apparaît pas.
3. Plusieurs enfants = plusieurs fiches, **toutes listées** dès qu'elles pointent sur
   le même téléphone/e-mail parent.

## 🟢 Naviguer dans l'espace parent (étape par étape)
1. Après connexion : l'**accueil parent** affiche la liste des enfants (cartes :
   photo, nom, classe).
2. **Touchez un enfant** → sa fiche complète (page « Détails enfant ») : identité,
   classe, école.
3. Le **menu enfant** (bouton des actions sur la fiche) ouvre ses rubriques :
   avis, présence, emploi du temps, devoirs, résultats, frais, cantine, bibliothèque,
   santé, cahier, transport, punitions, badges, professeurs.
4. Pour passer à un **autre enfant** : retour (flèche) vers l'accueil parent, puis
   toucher l'autre carte — chaque sélection **basculera tout l'espace**.
5. Les écrans ouverts affichent en tête **le nom de l'enfant actif** : vérifiez avant
   de payer un frais !

## 🟢 Payer pour le bon enfant
1. Menu enfant → **Frais** : la liste des dus de **cet enfant** (page 18.10).
2. Le paiement (mobile money, carte, USSD) est toujours **nommément rattaché** à
   l'enfant sélectionné.

## ✏️ Modifier
- Le parent **corrige son propre profil** (téléphone, e-mail, photo) : Profil →
  Modifier.
- Les informations des enfants (classe, contacts, documents) : **uniquement
  l'école** peut les changer, sur le web (PARTIE 06).

## 🔴 Supprimer / retirer un enfant
- Pas de suppression dans l'app : un enfant **radié, transféré ou majeur** est détaché
  par l'école sur le web — il disparaît alors de la liste parent.
- Se **déconnecter** ne retire rien.

## ♻️ Restaurer
- Enfant disparu de la liste : le lien parent-élève a été modifié/supprimé sur la fiche
  — demandez à l'école de **rétablir le rattachement** (PARTIE 06).
- Espace parent « vide » après connexion : le compte parent n'a **aucun enfant
  rattaché** (souvent un téléphone changé sans mise à jour de la fiche).
- Vous voyez **un enfant qui n'est pas le vôtre** : erreur de lien dans une fiche —
  signalez-le immédiatement à l'école, c'est une question de confidentialité.

## ⚠️ Bon à savoir
- Deux parents (père et mère) peuvent suivre **le même enfant** sur leurs téléphones
  respectifs : chacun se connecte avec **son** compte.
- Les notifications arrivent au parent **et** à l'élève : pas besoin de relayer
  soi-même une annonce publiée.
- L'accès **frais/paiement** est le plus sensible : toujours vérifier le nom en haut
  de l'écran avant de confirmer un débit.
- L'espace parent ne montre **rien d'autre** que ses enfants : pas d'accès aux
  classes complètes ni aux autres élèves.
