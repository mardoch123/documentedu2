# 📊 18.5 — EduStudent : consulter ses bulletins, résultats et rapports par matière

## 🎯 Rôle
L'élève (et le parent) voit ici **tous les chiffres de l'année** : bulletins
trimestriels, résultats d'examen détaillés, **rapport par matière**, et le
**service de vérification de bulletin** (authenticité par code).

## ✅ Prérequis
1. Être connecté (page 18.1).
2. Que l'école ait **publié** les résultats (c'est la direction qui publie les
   bulletins sur le web, PARTIE 09) : avant publication, l'écran est vide.

## 🟢 Consulter un bulletin (étape par étape)
1. Accueil → tuile **« Résultats »** (« Result »).
2. Choisissez la **session / l'année**, le **trimestre** et le **type d'examen**.
3. Le **bulletin** s'affiche : matières, notes/20 (ou barème école), moyennes,
   rang, appréciations des professeurs, décision du conseil.
4. Bouton **partager / PDF** : export du bulletin pour l'impression ou l'envoi.

## 🟢 Résultat en ligne (examen ponctuel)
1. Écran **« Résultat en ligne »** : note directe d'un **examen en ligne** déjà
   corrigé — aux questions/objectifs, avec le barème.
2. Apparaît dès que le professeur publie la correction.

## 🟢 Rapport par matière (progression)
1. Écran **« Rapports par matière »** : liste des matières de l'année.
2. Touchez une matière : le **détail de la progression** — devoirs faits/rendus,
   notes des évaluations, moyenne évolutive, thèmes suivis.
3. Le parent consulte le **même rapport pour son enfant** via son menu (page 18.3).

## 🟢 Vérifier l'authenticité d'un bulletin
1. Écran **« Vérification de bulletin »**.
2. Saisissez le **code de vérification** imprimé sur le document (format attendu :
   « Ex: EDU-REC-2025-A1B2C3D4 »).
3. Lancez : l'application confirme si le bulletin est **authentique** et renvoie la
   fiche associée (écran résultat de vérification).
4. Utilité : un employeur, une autre école ou une administration peut contrôler un
   bulletin papier sans risque de faux.

## ✏️ Modifier / contester
- **Aucune modification possible** depuis l'app — c'est voulu : l'élève et le parent
  **contestent** une note par le canal officiel (message au professeur ou
  secrétariat, page 18.16 ; demande écrite à la direction).
- La correction, si elle est acceptée, est **saisie sur le web** (PARTIE 09) puis
  republiée : le bulletin ici se met à jour tout seul.

## 🔴 Supprimer
- Un résultat publié ne se retire pas par l'app. Suppression/annulation de bulletin :
  direction, sur le web, avec justification.

## ♻️ Restaurer
- Bulletin « disparu » : mauvaise **session/année** sélectionnée dans les filtres du
  haut — revenez à l'année en cours.
- Note absente d'une matière : l'enseignant n'a **pas encore soumis** ses notes pour
  cette matière (voir le calendrier de collecte avec le prof).
- Code de vérification introuvable sur un vieux bulletin : redemandez un **duplicata
  certifié** à la direction (web, PARTIE 14 certificats).

## ⚠️ Bon à savoir
- Le **rang et la moyenne de classe** n'apparaissent que si l'école les active :
  leur absence n'est pas une erreur.
- La **moyenne générale du trimestre** dans l'app est calculée par l'école (pondération
  matières) : ne pas la recalculer soi-même pour contester.
- Le rapport par matière est le meilleur outil d'**accompagnement** : il montre quelles
  évaluations pèsent le plus avant le conseil de classe.
- Téléchargez chaque bulletin en **PDF** dès publication : en cas de changement
  d'établissement, c'est votre archive familiale.
