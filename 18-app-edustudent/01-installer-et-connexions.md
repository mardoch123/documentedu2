# 📱 18.1 — EduStudent : installer l'application, connexion élève et connexion parent

EduStudent est l'application des **familles** : chaque **élève** suit ses cours,
devoirs et notes ; chaque **parent** surveille ses enfants. Un même téléphone peut
servir aux deux — il y a **deux portes d'entrée distinctes**.

## 🎯 Rôle
- L'**espace élève** : emploi du temps, leçons, devoirs à rendre, examens en ligne,
  bulletins, cahier de liaison, badges.
- L'**espace parent** : le même regard sur **chacun de ses enfants**, plus les
  **frais à payer** (mobile money/USSD) et la santé.

## ✅ Prérequis
1. Que votre école utilise EduEasy et vous ait **inscrit** (admission PARTIE 06).
2. Identifiants **élève** : le **code de l'école** + votre **numéro GR** (matricule
   donné par l'école) + le **mot de passe**. ⚠️ Par défaut, le mot de passe élève est
   la **date de naissance au format JJMMAAAA** (ex. 05092012 pour le 5 septembre
   2012) — tel que communiqué à l'admission.
3. Identifiants **parent** : le **téléphone ou l'e-mail** enregistré dans la fiche du
   parent + le mot de passe (le **numéro de téléphone** par défaut). Le **code école**
   y est facultatif (l'app retrouve l'école toute seule, sinon « Code manuel »).

## 🟢 Installer et se connecter (étape par étape)
1. Installez **EduStudent** depuis le Play Store (Android) ou l'App Store (iPhone),
   ouvrez l'application.
2. Parcourez ou passez l'onboarding (présentation).
3. Écran d'entrée : deux boutons — **« Connexion Apprenant »** et, en bas, lien
   **« Vous êtes parent ? Connexion Parent »** (et l'inverse sur l'autre écran).
4. **Élève** : saisissez **Code de l'école** (ex. « ECOLE-001 »), **Numéro GR**,
   **Mot de passe** → Se connecter.
5. **Parent** : saisissez **Téléphone ou adresse e-mail** + **Mot de passe** (le code
   école est demandé seulement si la recherche automatique « Recherche du code
   établissement… » échoue — bouton « Code manuel »).
6. Acceptez la demande **« notifications »** : avis, devoirs et résultats y arrivent.
7. Premier connexion réussie : changez le mot de passe dans **Profil → Changer le mot
   de passe** (surtout l'élève, dont le mot de passe = date de naissance).

## 🟢 Basculer élève ↔ parent sur le même téléphone
1. Déconnexion (Profil → Déconnexion).
2. Re-connexion avec l'autre compte (un parent peut aussi suivre plusieurs enfants
   **sans** se reconnecter : sélection de l'enfant dans son espace, page 18.3).

## ✏️ Modifier
- **Mot de passe** : Profil → Changer le mot de passe (après changement, la date de
  naissance / le téléphone ne fonctionnent plus).
- **Photo et coordonnées du profil** : PROFIL → Modifier (l'élève ; le parent via
  « Profil parent »). Pour le reste (classe, parent rattaché), c'est l'école sur le
  web (PARTIE 06).

## 🔴 Supprimer / se déconnecter
- **Déconnexion** : aucune donnée perdue.
- **Désinstallation** : sans danger, tout est sur le serveur de l'école.
- La **suppression du compte** (élève radiaté, parent retiré) se fait par l'école sur
  le web, jamais dans l'app.

## ♻️ Restaurer / récupérer l'accès
- **Mot de passe oublié** : prévenez le secrétariat de l'école ; il **réinitialise**
  votre accès sur le web — il redevient la date de naissance (élève) ou le téléphone
  (parent).
- **Numéro GR perdu / incompris** : le matricule figure sur la carte d'identité
  scolaire et dans le courrier d'admission ; le secrétariat peut le redonner.
- Compteur d'enfants vide côté parent : le lien parent-élève est mal saisi dans la
  fiche — l'école le corrige (PARTIE 06 Parents).
- Compte d'élève supprimé par erreur : restauration par l'école sur le web — l'accès
  EduStudent revient tel qu'avant.

## ⚠️ Bon à savoir
- Message « identifiants incorrects » côté élève : vérifier le **code école**, le GR
  (majuscules/espaces), puis le format **JJMMAAAA** de la date de naissance.
- Erreur parent « Veuillez entrer votre numéro de téléphone ou email » : le champ
  attend le **téléphone complet** enregistré (avec l'indicatif si demandé), pas le
  nom.
- L'écran propose aussi **« Inscrire mon école »** : c'est pour une **nouvelle école**
  qui rejoint EduEasy — pas pour créer votre compte personnel.
- Écran « Application en maintenance » ou « Mise à jour obligatoire » : attendre /
  installer la mise à jour du store.
- Un parent **ne voit que ses enfants** : si un enfant manque, c'est le lien familial
  côté fiche scolaire qui est à corriger par l'école.
