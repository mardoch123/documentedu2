# 🧩 Champs personnalisés des fiches (Custom Fields)

## 🎯 Rôle
Ajouter à vos fiches élèves (et personnel) des **champs qui n'existent pas par défaut** et qui
sont propres à votre école : « Groupe sanguin », « Nom de l'ancien établissement », « Service de
cantine souhaité », « Numéro AMP »… Une fois créés ici, ces champs apparaissent **automatiquement
dans les formulaires d'admission et de modification**, et sont consultables/exportables.

## ✅ Prérequis
1. Permissions « form-fields-list / create / edit / delete ».
2. Savoir **quoi demander** (un champ par information utile ; trop de champs = formulaires lourds).
3. Accès : menu **Champs personnalisés (Custom Fields)**.

## 🟢 Créer un champ personnalisé (étape par étape)
1. Ouvrez **Champs personnalisés**.
2. Dans la carte **« Créer un champ »** : **choisissez le type de champ**, donnez-lui un **nom**,
   puis validez.
3. Types habituels : texte court, zone de texte long, nombre, date, oui/non (case), liste
   déroulante (choix fixes)… — le formulaire affiche un **aperçu en direct** de ce que
   l'utilisateur verra : profitez-en pour vérifier le rendu.
4. Cliquez sur **Soumettre / Créer**.
5. Le champ apparaît dans la **liste** et dans les fiches (étape « Renseignements
   Complémentaires » de l'admission d'un élève).

## ↕️ Réordonner les champs
La liste indique : « **Glissez-déposez les lignes pour changer leur ordre d'affichage** ».
1. Cliquez sur une ligne et **faites-la glisser** à la position voulue.
2. L'ordre choisi est celui affiché dans les formulaires élèves/personnel — mettez les plus
   importants en haut.

## ✏️ Modifier un champ
1. Liste des champs → **crayon ✏️** sur la ligne → fenêtre d'édition.
2. Changez le **nom**, les **options** (valeurs d'une liste) ou le caractère obligatoire.
3. **Mettre à jour**. ⚠️ Renommer un champ ne perd **pas** les réponses déjà saisies, mais
   supprimez/modifiez avec discernement si des fiches dépendent de la valeur.

## 🔴 Supprimer un champ
1. Sur la ligne, icône **poubelle 🗑** → confirmer (le champ part en **corbeille**).
⚠️ Les valeurs déjà remplies par les élèves deviennent invisibles tant que le champ est en
corbeille — elles ne sont pas effacées (voir restauration).

## ♻️ Restaurer un champ supprimé
1. En haut de la liste, cliquez sur l'onglet **« Trashed »** (Corbeille) — le commutateur
   « all | Trashed » est au-dessus du tableau.
2. Retrouvez le champ → icône **restaurer ♻️** → confirmez.
3. Le champ réapparaît dans les fiches **avec toutes les valeurs déjà saisies**.

## ⚠️ Bon à savoir
- **Un champ = une question claire** : « Tranche de bus » plutôt que « Transport (préciser) ».
- Créez vos champs **AVANT la grande campagne d'admission** : les fiches déjà remplies auront
  le nouveau champ vide à compléter plus tard.
- Les champs personnalisés suivent les fiches dans les **exports** des listes élèves.
- Pour un choix qui revient souvent (oui/non, listes), préférez un **type liste/case** :
  saisie plus rapide et données propres (pas de « Oui », « oui », « OUI »…).
- Le même écran gère les champs du **personnel** : choisissez bien la cible lors de la création.
