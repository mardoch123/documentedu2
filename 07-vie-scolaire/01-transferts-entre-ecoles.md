# ↔️ Module Transferts entre écoles (vue « Vie scolaire »)

## 🎯 Rôle
Le module **Transferts** gère les **mouvements d'élèves entre établissements** : ceux que
d'autres écoles vous **envoient** (à valider), ceux que vous **envoyez** (invitations), et
ceux qui ont été **rejetés** (à corriger). La procédure détaillée pas à pas se trouve dans
**[05-academique-mobilite/02-transferer-eleve-autre-ecole.md]** ; cette page en est le
**rappel synthétique** côté Vie scolaire, avec les points de contrôle à connaître.

## ✅ Prérequis
1. L'élève concerné a une **fiche** dans votre école.
2. Permission « transfer-student-create ».
3. Accès : menu **Académique → Mobilité & Parcours → Transferts**, ou
   onglets du module Vie scolaire.

## 🔁 Les 3 onglets du module (à retenir)
| Onglet | Ce que vous y faites |
|---|---|
| **Reçues** (transferts entrants) | Ouvrir le « Dossier de transfert », choisir la **Classe de destination ★**, puis **✔ Valider & Intégrer** ou **✘ Rejeter**. |
| **Invitations envoyées** | Suivre l'état de vos transferts sortants, télécharger le **PDF 📄** du dossier. |
| **Rejetés** | Lire le **Motif**, corriger, puis **Retenter ↻** (gratuit pendant le **délai de grâce de 30 jours**). |

## 🟢 Lancer un transfert sortant (rappel)
1. **Élèves → Info Apprenant** → clic sur le nom de l'élève → **Transférer**.
2. Choisir le type : **Interne** (école EduEasy — rechercher par nom) ou
   **Externe** (invitation par **email** de l'école destinataire).
3. **Confirmer le transfert**. L'élève affiche « Transfert en cours » puis
   « Apprenant transféré avec succès » (nom barré).

## ✏️ / 🔴 Annuler, corriger
- Transfert **en attente** : non modifiable ; attendez un rejet puis relancez.
- Transfert **validé par erreur** : l'élève est parti avec son dossier → demandez un
  **transfert de retour** à l'autre école, ou recréez la fiche.

## ♻️ Restaurer
Un transfert réussi **n'est pas une suppression** (l'élève reste en historique, nom barré).
Ne le supprimez pas. Pour le remettre actif chez vous : transfert entrant de l'autre école,
ou **Support EduEasy** si besoin.

## ⚠️ Bon à savoir
- Réglez les **frais impayés** (badges rouge/jaune) **avant** de transférer : le dossier part
  avec la dette.
- **Transfert ≠ Promotion interne** : rester dans la même école mais changer de classe se fait
  via *05-academique-mobilite/01-promouvoir-transférer-eleves-interne.md*.
