# Documentation EduEasy — Sommaire général

> **À qui s'adresse ce document ?** À toutes les personnes qui utilisent EduEasy au quotidien
> (directeurs, secrétaires, comptables, enseignants, personnel), **même sans aucune compétence technique**.
> Chaque fonctionnalité possède **sa propre page** qui explique : à quoi elle sert, ce qu'il faut préparer
> avant, **comment faire l'action pas à pas**, comment la **modifier**, la **supprimer** et la **restaurer** après suppression.

---

## Comment lire une page de la documentation

Chaque page suit toujours la même structure, pour que vous ne vous perdiez jamais :

| Section de la page | Ce que vous y trouvez |
|---|---|
| 🎯 **Rôle** | À quoi sert la fonctionnalité, en une phrase simple |
| ✅ **Prérequis** | Ce qui doit exister AVANT de commencer (autre module, droit, donnée) |
| 🟢 **Comment créer** | Les étapes numérotées, clic par clic |
| ✏️ **Comment modifier** | Comment corriger une fiche existante |
| 🔴 **Comment supprimer** | Suppression classique ou « passage à la corbeille » |
| ♻️ **Comment restaurer** | Récupérer un élément supprimé (quand la corbeille existe) |
| ⚠️ **Bon à savoir** | Pièges fréquents, conseils, messages d'erreur courants |

> **Règle d'or dans EduEasy :** la plupart des éléments (classes, matières, élèves, frais…) ne sont pas
> détruits quand vous cliquez sur « Supprimer » : ils partent dans une **corbeille** (onglet « Trashed »
> ou filtre « Corbeille ») et peuvent être **restaurés**. Seules certaines actions (notées explicitement
> « irréversible » dans les pages) suppriment définitivement.

---

## Organisation du menu latéral (sidebar)

Le menu change selon **votre rôle**. Les deux grands espaces sont :

1. **L'espace ÉCOLE** (Directeur / School Admin, Enseignant, Staff) : tout ce qui gère l'établissement.
2. **Le support** : visible par tous, en bas du menu (« Support 24/7 »).

> ℹ️ Les menus réservés à l'équipe EduEasy (Super Admin : création des comptes écoles,
> abonnements, commerciaux, paramètres système) ne sont pas décrits dans ce guide,
> qui s'adresse aux **écoles, aux professeurs et au personnel**.

## Glossaire rapide (mots affichés à l'écran)

| Terme à l'écran | Signification simple |
|---|---|
| **Medium / Médium** | Langue d'enseignement de la classe (ex. Français, Bilingue) |
| **Section** | Lettre qui identifie un groupe d'élèves d'une même classe (A, B, C…) |
| **Stream / Filière** | Orientation (Sciences, Littéraire, Technique…) |
| **Shift / Service** | Période horaire (Matin, Après-midi, Soir) |
| **Syllabus** | Programme officiel d'une matière pour une classe |
| **Semester** | Semestre ou trimestre de l'année scolaire |
| **Fee / Frais** | Argent demandé aux élèves (scolarité, cantine…) |
| **Guardian** | Parent ou tuteur légal d'un élève |
| **Roll Number / Matricule** | Numéro officiel de l'élève dans sa classe |
| **Trashed / Corbeille** | Éléments supprimés mais récupérables |
| **Add-on** | Option payante ajoutée à l'abonnement |
| **Package / Forfait** | Formule d'abonnement de l'école (brise, standard, premium) |

> 📌 **Le menu peut afficher 🔒 (cadenas)** : cela veut dire que le module n'est pas inclus dans
> l'abonnement de l'école. Contactez la direction de l'école ou le support EduEasy pour l'activer.
