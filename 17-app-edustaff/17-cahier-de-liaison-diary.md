# 📔 17.17 — EduStaff : le cahier de liaison numérique (notes aux parents)

## 🎯 Rôle
Écrire dans le **cahier personnel d'un élève** une note datée et classée (devoir,
louange, incident, information) : les parents la lisent instantanément sur
EduStudent, et l'école garde l'historique complet des échanges.

## ✅ Prérequis
1. Être connecté à EduStaff (page 17.1).
2. Que le module **diary/cahier** existe pour l'école (l'équivalent web : PARTIE 13).
3. Avoir des classes affectées (pour ne écrire qu'aux élèves dont vous vous occupez).

## 🟢 Rédiger une note (étape par étape)
1. Accueil → **« + »** → famille **Ajouts rapides** → **« Note au cahier »**
   (ou tuile « Gérer le cahier »).
2. Choisissez d'abord **l'élève** : par classe puis par nom (écran de sélection).
3. Écran **« Ajouter une note »** :
   - saisissez le **titre de la note** ;
   - rédigez la **description / message** ;
   - choisissez la **date** de la note (par défaut aujourd'hui) ;
   - sélectionnez la **catégorie** (devoir, punition, louange, information…) ;
   - rattachez une **matière** si la note concerne un cours précis.
4. Appuyez sur **Enregistrer** : la note s'affiche aussitôt dans le cahier EduStudent
   de l'élève et dans la messagerie des parents.

## 🟢 Consulter le cahier d'un élève
1. Écran **« Cahier de l'élève »** : sélectionnez classe puis élève.
2. L'historique complet s'affiche, **par date**, avec catégorie et auteur de chaque
   note.
3. Les réponses des parents (quand l'école les active) apparaissent en face de la note.

## 🟢 Gérer les catégories (direction)
1. Menu **« Gérer les catégories »** du module cahier.
2. **Créer** : nommez une catégorie (ex. « Félicitations ») → Enregistrer.
3. **Modifier** : icône crayon sur la catégorie, changez le nom, validez.
4. Utilisées dans les notes : les catégories existantes guident tous les rédacteurs.

## ✏️ Modifier une note
1. Ouvrez le cahier de l'élève → touchez la note → icône **Modifier**.
2. Ajustez titre, message, date, catégorie ou matière → **Mettre à jour**.
3. Les parents voient la version corrigée ; l'horodatage de modification reste
   traçable côté web.

## 🔴 Supprimer une note
1. Ouvrir la note → icône **Supprimer** → confirmer.
2. ⚠️ Dans l'app, la suppression est **définitive** : si la note avait déjà été lue
   par les parents, prévenez-les ou recréez une note d'excuse.

## ♻️ Restaurer
- Note effacée par erreur : **recréez-la** le plus vite possible avec le même contenu
  (gardez une copie du texte important dans vos notes avant suppression).
- Catégorie manquante dans la liste : la direction la **recrée** dans « Gérer les
  catégories » ; les anciennes notes gardent leur libellé d'origine.
- Cahier vide pour un élève transféré : ses notes suivent l'élève côté web (PARTIE
  07 Transferts), pas dans l'app.

## ⚠️ Bon à savoir
- Une note **datée du futur** n'alerte pas les parents avant la date : pratique pour
  programmer un rappel.
- Gardez **titre court, message précis** : le titre s'affiche en notification push.
- Ne consignez pas dans le cahier une **punition officielle** : utilisez l'écran
  punitions (page 17.18) qui suit le circuit de validation de l'école.
- Les catégories personnalisées (direction) évitent le fourre-tout « autre » : créez
  la bonne catégorie avant d'écrire la note.
