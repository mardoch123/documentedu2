# ⚙️ 17.29 — EduStaff : profil, mot de passe, contacts et écrans divers

## 🎯 Rôle
Les écrans **personnels et fourre-tout** d'EduStaff : compléter sa fiche, changer son
mot de passe, lire les textes de l'application, contacter l'école ou EduEasy,
rechercher n'importe qui, et — pour les groupes scolaires — suivre plusieurs écoles.

## ✅ Prérequis
Être connecté (page 17.1). Tout le monde a ces écrans ; seul le **tableau de groupe
scolaire** est réservé à la direction multi-établissements.

## 🟢 Mon profil (onglet Profil / avatar du haut)
1. **Modifier son profil** (écran « Modifier le profil ») : photo, nom affiché,
   téléphone, e-mail, adresse — puis **Enregistrer**.
2. ⚠️ Certaines identités (matricule personnel, rôle) ne s'éditent que sur le web
   (PARTIE 11).

## 🟢 Changer son mot de passe
1. Profil → **« Changer le mot de passe »**.
2. Saisir l'**ancien** (le téléphone à la 1ʳᵉ connexion, page 17.1), puis le
   **nouveau deux fois**.
3. Valider : l'ancien cesse de fonctionner immédiatement sur tous les téléphones.

## 🟢 Rechercher une personne
- **« Rechercher des enseignants »** : annuaire profs (matières, contact) — utile pour
  trouver un remplaçant.
- **« Rechercher des utilisateurs »** : tous les comptes de l'école (profs, staff,
  parents) — version direction, avec la fiche qui s'ouvre.

## 🟢 Signalements et suggestions (écran « Mes rapports »)
1. Profil → **« Mes rapports / suggestions »**.
2. **Nouveau signalement** : catégorie, description — transmis à la direction de
   l'école (pas au support EduEasy).
3. Suivi du statut de vos rapports précédents.

## 🟢 Demande d'information école (schoolInquiry)
Écran **« Contact / Demande d'information »** : message ciblé pour le secrétariat de
votre école (inscription d'un proche, question logistique interne).

## 🟢 Tableaux du groupe scolaire (direction multi-établissements)
1. Écran **« Groupe scolaire »** (dashboard) : vos **écoles rattachées** côte à côte —
   effectifs, présences, recettes du jour par établissement.
2. Touchez une école : ses indicateurs détaillés ; la bascule de gestion complète se
   fait sur le web (PARTIE 15 « Groupe scolaire »).

## 🟢 Les pages texte
- **À propos** : version de l'application, coordonnées EduEasy.
- **Conditions d'utilisation** et **Politique de confidentialité** : à lire une fois,
  en surtout la partie données des élèves.
- **Contact / Support** : les voies rapides vers votre école et vers EduEasy.

## ✏️ / 🔴 / ♻️
- **Photo de profil** : remplacez à volonté (dernière enregistrée gagne).
- **Signalement envoyé** : modifiable tant que non traité ; supprimable pour votre
  affichage, jamais pour la direction qui garde la trace.
- **Mot de passe oublié** : pas de réinitialisation autonome dans l'app — la direction
  réinitialise sur le web, le mot de passe redevient le **numéro de téléphone**
  (page 17.1).
- Compte verrouillé après erreurs répétées : attendez le délai indiqué ou demandez
  à la direction de déverrouiller sur le web.

## ⚠️ Bon à savoir
- L'**e-mail de profil** doit rester juste : c'est lui qui reçoit les copies de
  notifications critiques de l'école.
- Le badge de **version** (écran À propos) sert au Support : notez-le avant tout
  signalement de bug.
- Sur un **groupe scolaire**, le tableau mobile est en lecture : aucune configuration
  d'école ne se change ici.
- Se **déconnecter** (Profil → Déconnexion) ne supprime aucune donnée — désinstaller
  non plus (page 17.1).
