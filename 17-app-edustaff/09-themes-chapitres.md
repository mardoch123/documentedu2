# 🧩 17.9 — EduStaff : suivre le programme par thèmes (chapitres)

## 🎯 Rôle
Déclarer les **thèmes/chapitres du programme officiel** d'une matière et suivre leur
**avancement** (à faire, en cours, complété) — la colonne vertébrale de la progression
annuelle, visible par la direction et les élèves.

## ✅ Prérequis
1. Être connecté à EduStaff (page 17.1) avec des matières affectées.
2. Avoir créé (ou vu créer) les **leçons** correspondantes (page 17.8) : le thème est
   le cadre, la leçon est la séance.

## 🟢 Créer un thème (étape par étape)
1. Accueil → tuile **« Thèmes »** (ou « Topics ») → bouton **ajouter (+)**.
2. Choisissez la **classe/section** concernée.
3. Choisissez la **matière**.
4. Choisissez la **leçon** à laquelle rattacher le thème (liste des leçons déjà créées
   pour ce couple classe-matière).
5. Saisissez le **nom du thème** (ex. « Chapitre 3 : Les équations du premier degré »).
6. Ajoutez la **description** : sous-points, objectifs, durée prévue.
7. **Enregistrer** : le thème rejoint la liste et le programme vu côté élèves.

## 🟢 Gérer et suivre les thèmes
1. Écran **« Gérer les thèmes »** : liste filtrable par classe/matière.
2. Chaque thème porte un **statut** : complété, en cours, à faire — touchez-le pour
   changer l'état d'avancement au fil de l'année.
3. Les élèves EduStudent consultent les thèmes **complétés** comme le programme suivi.

## ✏️ Modifier
1. Liste → ouvrez le thème → icône **Modifier** (titre devient « Modifier le thème »).
2. Ajustez classe, matière, leçon liée, nom ou description.
3. **Mettre à jour**. Le changement est instantané partout.

## 🔴 Supprimer
1. Ouvrir le thème → icône **Supprimer** → confirmer.
2. ⚠️ Sans corbeille mobile : les leçons rattachées **restent**, seul le cadre thème
   disparaît ; les élèves ne voient plus le chapitre.

## ♻️ Restaurer
- Thème supprimé par erreur : **recréez-le** avec le même nom — les leçons peuvent être
  rattachées à nouveau une par une.
- Thème « introuvable » : vérifiez les filtres classe/matière en haut de liste.
- Statut d'avancement faux après fusion d'années : l'ancien programme se consulte sur
  le web (PARTIE 13), l'app n'affiche que l'année active.

## ⚠️ Bon à savoir
- Créer les **thèmes en début d'année** (même non faits) donne un tableau de progression
  parlant pour la direction : il ne reste qu'à passer les statuts.
- Un même thème peut exister pour **plusieurs sections** : refaites l'ajout par section,
  le nom identique suffit à les reconnaître.
- Le nom du thème s'affiche aux parents via EduStudent : restez clair et sans abréviations.
- Les blocs « classe/matière/leçon » sont obligatoires dans cet ordre : si la liste des
  leçons est vide, créez d'abord la leçon (page 17.8).
