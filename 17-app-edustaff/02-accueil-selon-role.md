# 🏠 17.2 — L'accueil EduStaff selon votre rôle (onglets, tuiles, bouton « + »)

## 🎯 Rôle
L'écran d'accueil est le **tableau de bord personnel** de chaque membre du personnel :
résumé de la journée, accès rapides à vos classes, et bouton « + » pour les actions
fréquentes. Son contenu **s'adapte automatiquement** à votre rôle (enseignant ou direction).

## ✅ Prérequis
1. Être connecté à EduStaff (page 17.1).
2. Avoir Internet : l'accueil charge les données du serveur de l'école à l'ouverture.

## 🧭 Que trouve-t-on sur l'accueil (de haut en bas)
1. **Barre du haut** : le nom de votre école, votre photo, et des icônes utiles —
   solde/compte **USSD** (badge avec numéro), cloche de **notifications** 🔔, recherche.
2. **Résumé du jour** : petites cartes avec vos chiffres du moment (présence appelés,
   élèves, paiements du jour, selon votre rôle).
3. **Sections académiques adaptatives** : cartes « Mes classes », « Mes leçons »,
   « Mes devoirs », « Mon emploi du temps »… un enseignant voit ses propres classes ;
   la direction voit les sections globales de l'école.
4. **Barre « Actions Rapides »** : une rangée de raccourcis que **vous choisissez**
   (voir « Modifier » ci-dessous).
5. **Bouton rond « + »** (en bas à droite) : ouvre le grand panneau d'actions, rangé en
   **5 familles** :
   - **Encaissement & Paiements** — encaisser un frais, transfert, reçu, imprimante ;
   - **Validations & Suivi** — valider devoirs, notes, congés, demandes ;
   - **Ajouts rapides** — ajouter un élève, une leçon, une annonce, une note… ;
   - **Gestion du personnel** — enseignants, staff, parents, chauffeurs (direction) ;
   - **Outils** — scan QR, bibliothèque, cantine, santé, générateurs IA…
6. **Navigation du bas** : Accueil, Chat, Profil.

## 🟢 Utiliser l'accueil (étape par étape)
1. Ouvrez l'application : l'accueil s'affiche (dernier résumé enregistré, puis à jour).
2. Pour ouvrir une section, **touchez la tuile** : l'écran correspondant s'affiche.
3. Pour une action rare, touchez **« + »**, choisissez la **famille**, puis l'action.
4. Le badge 🔔 signale les validations en attente ; touchez-le pour traiter directement.
5. Tirez l'écran **vers le bas** pour rafraîchir les chiffres.

## ✏️ Modifier — personnaliser la barre « Actions Rapides »
1. Dans la barre « Actions Rapides », touchez l'icône **crayon / gestion**.
2. **Activez ou désactivez** chaque raccourci (case ou switch par action).
3. **Réordonnez** en maintenant-déplaçant les tuiles.
4. **Validez** : votre choix est **enregistré sur le téléphone** et conservé entre les sessions.

## 🔴 Masquer / retirer
- Un raccourci de la barre Actions Rapides se **retire** en le désactivant (page « + »
  reste disponible, rien n'est perdu).
- Les tuiles académiques **ne se suppriment pas** : elles suivent votre rôle et vos
  affectations de classes, gérées sur le web (PARTIE 11).

## ♻️ Restaurer
- Raccourci masqué par erreur : rouvrez la gestion de la barre et **réactivez-le**.
- Vous ne retrouvez plus une action connue : cherchez-la dans le panneau **« + »** — la
  plupart des fonctions y sont, même hors de la barre.
- Écran vide ou chiffres anciens : **tirez vers le bas** pour rafraîchir ; si le rôle
  a changé sur le web, déconnectez-reconnectez pour charger les nouveaux menus.

## ⚠️ Bon à savoir
- **Deux collègues n'ont pas le même accueil** : c'est voulu (rôle, classes affectées,
  autorisations), pas un bug.
- Sur l'enseignant, certaines tuiles direction (paie du personnel, encaissements) sont
  **absentes** ; basculez en espace Direction si votre compte y est autorisé
  (bouton de changement d'espace dans le profil).
- Le badge USSD indique le **nombre de transactions USSD** en attente de vérification.
- En connexion faible, l'accueil peut afficher l'ancien résumé : les chiffres se
  corrigent dès que la charge aboutit.
