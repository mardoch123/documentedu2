# 📣 17.11 — EduStaff : annonces de classe et notifications

## 🎯 Rôle
Prévenir **vos élèves** (annonce de classe) ou **toute l'école** (notification de la
direction) : changement de salle, convocation, rappel de devoir, info urgente — sans
passer par le web.

## ✅ Prérequis
1. Être connecté à EduStaff (page 17.1).
2. Pour une annonce de classe : avoir la classe concernée affectée.
3. Pour les **notifications globales** (direction) : être School Admin ou habilité ;
   l'enseignant publie des annonces, la direction publie des notifications.

## 🟢 Publier une annonce de classe (étape par étape)
1. Accueil enseignant → tuile **« Annonces »** (enseignant : « Gérer mes annonces »).
2. Bouton **ajouter (+)**.
3. Choisissez la **classe/section** destinataire (et la matière si demandé).
4. Saisissez le **titre** (court, ex. « Interrogation jeudi 8h »).
5. Rédigez le **message** (détails, consignes, date/heure).
6. Fixez la **date d'expiration** si l'écran la propose (au-delà, l'annonce sort des
   écrans élèves).
7. **Publier / Enregistrer** : l'annonce arrive en notification sur EduStudent des
   élèves concernés.

## 🟢 Direction : notification générale
1. Panneau **« + »** → famille **Ajouts rapides** → **« Nouvelle notification »**
   (ou « Gérer les notifications »).
2. Titre + message + destinataires choisis par l'écran (élèves, parents, personnel).
3. **Publier** : push immédiat sur les téléphones (nécessite que les notifications
   soient autorisées par le destinataire).

## 🟢 Consulter les annonces reçues
1. Tuile **« Annonces »** (liste) ou cloche 🔔 de la barre du haut.
2. Les annonces lues/non lues sont séparées ; touchez pour lire le détail.
3. Écran **« Notifications »** (direction) : liste de ce que VOUS avez publié, avec
   possibilité d'agir dessus.

## ✏️ Modifier
1. Liste de **vos** annonces → ouvrez l'annonce → icône **Modifier**.
2. Changez titre/message/date → **Mettre à jour**. Les destinataires voient la version
   corrigée.
3. ⚠️ Une correction ne « re-notifie » pas forcément : pour une urgence, publiez une
   nouvelle annonce courte pointant vers la correction.

## 🔴 Supprimer / retirer
1. Ouvrir l'annonce → icône **Supprimer** → confirmer.
2. L'annonce disparaît des écrans élèves ; aucune corbeille mobile — la suppression
   est définitive.

## ♻️ Restaurer
- Annonce supprimée par erreur : **republiez-la** (gardez le texte dans vos notes).
- Élève dit n'avoir rien reçu : vérifiez (1) la classe destinataire de l'annonce,
  (2) que son **autorisation de notifications** est activée, (3) son connexion.
- Notification de la direction restée en brouillon : les écrans « Gérer les
  notifications » distinguent publiées / non publiées — rouvrez et publiez.

## ⚠️ Bon à savoir
- **Annonce** = une classe (l'enseignant) ; **notification** = publique large
  (direction). Ne pas noyer toute l'école pour une seule classe.
- Une annonce avec **date d'expiration** nettoie seule les écrans : pratique pour les
  infos ponctuelles.
- Le titre s'affiche en **push** sur le téléphone Verrouillage : écrivez l'info clé
  dedans (« Interro jeudi 8h — Term C »).
- Les parents EduStudent reçoivent les annonces **de la classe de leur enfant** ; pas
  besoin de les cibler séparément.
