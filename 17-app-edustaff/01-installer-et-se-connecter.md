# 📲 17.1 — EduStaff : installer l'application et se connecter

EduStaff est l'application Android/iPhone du **personnel de l'école** (enseignants,
direction, administration). Elle remplace l'ouverture d'EduEasy sur ordinateur quand vous
êtes en déplacement ou en classe.

## 🎯 Rôle
- Donner à chaque membre du personnel ses outils dans la poche : appel des élèves,
  leçons, devoirs, notes, encaissements, congés, paie, messages.
- Afficher **uniquement ce que votre rôle autorise** : un enseignant ne voit pas
  l'écran de paie des autres, la direction voit tout.

## ✅ Prérequis
1. Que votre école utilise EduEasy.
2. Avoir un **compte personnel créé par la direction** (enseignant ou staff) — voir
   PARTIE 11. Vous devez connaître :
   - votre **e-mail** (ou mobile) d'accès ;
   - le **code de votre école** (ex. `ECOLE-001`) — communiqué par la direction,
     visible aussi dans EduEasy web ;
   - votre **mot de passe**. ⚠️ À la toute première connexion, le mot de passe
     par défaut est **votre numéro de téléphone** tel qu'enregistré dans votre fiche.
3. Un téléphone avec Internet (3G/4G/Wi-Fi).

## 🟢 Installer et se connecter (étape par étape)
1. Ouvrez le **Play Store** (Android) ou l'**App Store** (iPhone) et cherchez « EduStaff ».
2. Installez l'application, puis ouvrez-la.
3. L'écran d'accueil propose les pages de présentation (onboarding) : parcourez-les ou
   passez-les avec « Suivant » / « Passer ».
4. Sur l'écran de connexion, remplissez les **trois champs** :
   - **Code école** (indice affiché : « Ex: ECOLE-001 ») ;
   - **E-mail** (indice : « nom@ecole.com ») ;
   - **Mot de passe** (votre téléphone à la première connexion).
5. Appuyez sur **Se connecter**. L'accueil s'ouvre avec vos menus.
6. Le téléphone demande **« Autoriser les notifications »** : acceptez, sinon vous
   raterez annonces et alertes.
7. Première connexion réussie ? Allez tout de suite dans **Profil → Changer le mot de
   passe** pour choisir un mot de passe personnel.

## ✏️ Modifier
- **Changer de mot de passe** : icône Profil → Changer le mot de passe (ancien, puis
  nouveau deux fois). Après ce changement, le téléphone ne sera plus le mot de passe.
- **Compléter son profil** (photo, coordonnées) : Profil → Modifier → Enregistrer.
- **Langue de l'application** : dans les options du profil (français / anglais).

## 🔴 Supprimer / se déconnecter
- **Se déconnecter** : Profil → Déconnexion. Aucune donnée n'est effacée de l'école.
- **Désinstaller l'application** : sans danger, tout reste sur le serveur ; réinstallez
  et reconnectez-vous pour tout retrouver.
- **Supprimer un compte personnel** : ne se fait PAS dans l'application — c'est la
  direction, sur le web (menu « Personnel », PARTIE 11).

## ♻️ Restaurer / récupérer l'accès
- **Mot de passe oublié ou perdu** : prévenez le secrétariat ; la direction peut
  **réinitialiser votre mot de passe** depuis sa fiche Personnel — il redevient alors
  votre **numéro de téléphone**, à changer dès la connexion.
- **Compte supprimé par erreur** : la direction le restaure depuis la corbeille du web
  (PARTIE 11) ; votre accès mobile redevient actif tel qu'avant.
- **Nouveau téléphone** : installez EduStaff, connectez-vous avec les mêmes identifiants,
  tout est immédiatement à jour (aucune donnée n'est stockée seulement sur le téléphone).

## ⚠️ Bon à savoir
- Message « identifiants incorrects » : vérifiez le **code école** (faute de frappe),
  puis que vous utilisez bien le téléphone comme mot de passe si c'est la 1ʳᵉ connexion.
- L'écran peut afficher **« Application en maintenance »** : la plateforme prépare une
  mise à jour, réessayez plus tard.
- Une fenêtre **« Mise à jour obligatoire »** bloque l'usage tant que vous n'avez pas
  installé la dernière version depuis le store.
- Vos menus peuvent différer de ceux d'un collègue : c'est votre rôle et vos
  autorisations, pas un bug (voir page 17.2).
- Écran de connexion lent en 3G : normal, l'application interroge le serveur de l'école ;
  vérifiez la couverture plutôt que de relancer dix fois.
