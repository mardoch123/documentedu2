# 🎒 17.6 — EduStaff : mes classes, sections et la fiche des élèves

## 🎯 Rôle
Retrouver en quelques secondes **les classes dont vous avez la charge**, la liste de
leurs **élèves actifs**, et la **fiche complète** d'un élève (identité, parent, frais,
présence, bulletins).

## ✅ Prérequis
1. Être connecté à EduStaff (page 17.1).
2. Avoir des classes/sections affectées par la direction (professeur principal ou
   enseignant de matières).
3. Pour la liste d'élèves : que le module élèves existe sur le web (PARTIE 06).

## 🟢 Voir mes classes (étape par étape)
1. Accueil → tuile **« Mes classes »** / « Class Section ».
2. La liste montre vos **classes et sections** de l'année en cours : nom complet
   (ex. « Terminale C — 42 élèves »), effectif, salle habituelle.
3. Touchez une classe : vous accédez à ses **élèves**, son **emploi du temps**, ses
   **matières**.
4. Message « aucune section trouvée » : vous n'avez pas d'affectation cette année —
   voyez la direction.

## 🟢 Chercher un élève et ouvrir sa fiche
1. Accueil → tuile **« Élèves »** (« Students ») ou depuis une classe.
2. En haut : filtres **classe/section** et **année**.
3. Tapez le **nom** dans la recherche : la liste se filtre en direct (attendez une
   demi-seconde, la recherche est automatisée).
4. Touchez l'élève → **fiche complète** : photo, matricule, date de naissance,
   classe, parent/tuteur et ses contacts, historique de présence, frais, bulletins
   selon vos droits.
5. Depuis la fiche, raccourcis vers : **faire l'appel** de sa classe, voir ses
   **devoirs**, ses **notes**.

## 🟢 Direction : ajouter un élève rapidement
1. Bouton **« + »** → famille **Ajouts rapides** → **« Nouvel élève »**.
2. Formulaire d'admission abrégé (identité, classe, parent) — l'équivalent mobile du
   formulaire web PARTIE 06.
3. Enregistrez : l'élève apparaît aussitôt dans les listes et l'accès EduStudent est
   préparé (mot de passe = date de naissance).

## ✏️ Modifier
- La fiche élève **se consulte** dans l'app ; les modifications lourdes (changement de
  classe, parent, documents) se font sur le **web** par le secrétariat (PARTIE 06).
- Le **profil d'une section** (nom, titulaire) se change aussi sur le web (PARTIE 03).

## 🔴 Supprimer
- Jamais depuis l'application : un élève se retire sur le web (PARTIE 06), avec
  corbeille et restauration.

## ♻️ Restaurer
- Élève « introuvable » dans la recherche : il est peut-être **inactif/transferé** —
  changez le filtre de statut, ou vérifiez l'année scolaire sélectionnée.
- Classe disparue de « Mes classes » : l'affectation a changé sur le web ;
  déconnectez-reconnectez pour recharger.

## ⚠️ Bon à savoir
- Les listes d'élèves affichent uniquement les **actifs** de l'année : un redoublant
  ou un transféré n'apparaît que si vous changez le filtre année/statut.
- Un parent peut avoir **plusieurs enfants** dans l'école : chaque fiche est séparée,
  le lien parent figure dans les deux.
- La fiche mobile montre **ce que votre rôle autorise** : un simple professeur de
  matière peut ne pas voir les frais de l'élève.
- Recherche sensible aux fautes : tapez seulement le **début du nom** ou le
  **prénom** pour retrouver un élève dont l'orthographe vous échappe.
