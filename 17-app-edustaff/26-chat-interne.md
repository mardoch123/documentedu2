# 💬 17.26 — EduStaff : la messagerie interne de l'école (chat)

## 🎯 Rôle
Discuter **entre membres de la même école** (enseignants, staff, direction) dans
l'application : réponses rapides, photos de documents, sans sortir du cadre
professionnel — l'équivalent du chat web EduEasy (PARTIE 08).

## ✅ Prérequis
1. Être connecté à EduStaff (page 17.1).
2. Avoir au moins **un collègue** avec compte actif dans la même école.
3. L'onglet **Chat** est accessible en bas de l'écran d'accueil.

## 🟢 Démarrer une conversation (étape par étape)
1. Onglet **Chat** de la barre du bas.
2. Bouton **nouvelle conversation** (crayon / « + ») : écran « Nouveaux contacts ».
3. Cherchez un **collègue** par nom (liste filtrable par rôle).
4. Sélectionnez la personne → la conversation s'ouvre.
5. Tapez dans le champ du bas et **Envoyez** : message instantané, accusé de lecture
   selon les options de l'école.

## 🟢 Envoyer autre chose que du texte
1. Dans une conversation, icône **pièce jointe** (trombone ou image).
2. Choisissez **photo ou fichier** depuis le téléphone (photo d'une fiche, scan d'un
   justificatif…).
3. Rédigez un commentaire court si besoin, puis **Envoyer**.

## 🟢 Gérer ses conversations
1. L'onglet Chat liste toutes les conversations : **dernier message, heure, badge de
   non lus**.
2. **Rechercher** une conversation via le champ du haut.
3. Ouvrir → dérouler l'historique ; les messages restent tant que l'école ne purge
   pas (politique de l'établissement).

## ✏️ Modifier / supprimer un message
- Un message envoyé peut se **supprimer** pour vous (appui long → « Supprimer ») ; la
  suppression **pour tous** n'existe que si l'école l'active — sinon, assumez ce qui
  est parti.
- Il n'y a pas d'édition de message envoyé : envoyez un correctif court (« lire :
  … »).

## 🔴 Quitter / effacer une conversation
1. Appui long sur la conversation dans la liste → **Supprimer la conversation** :
   l'historique disparaît **de votre écran** (pas de celui du collègue).
2. Rien de définitif côté serveur si la direction archive les échanges : usage
   professionnel oblige.

## ♻️ Restaurer
- Conversation disparue de la liste : le collègue vous **recontacte**, ou vous
  recréez la conversation (mêmes contacts, nouveaux fils).
- Message important perdu après suppression locale : il existe encore chez le
  destinataire — demandez une capture.

## ⚠️ Bon à savoir
- Le chat interne **ne remplace pas les annonces officielles** : une consigne pour
  tous passe par l'annonce (page 17.11), pas par 30 messages privés.
- Photos d'élèves ou documents administratifs : restez dans le strict besoin
  professionnel — l'école peut auditer les échanges.
- Notifications chat coupées : vérifiez l'autorisation de notifications (page 17.1)
  et le mode « Ne pas déranger » du téléphone.
- Hors de l'école, la messagerie **parent/élève** est sur EduStudent : vous n'y
  répondez que si l'école active le canal enseignant.
