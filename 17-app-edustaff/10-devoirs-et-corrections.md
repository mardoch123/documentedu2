# ✍️ 17.10 — EduStaff : donner des devoirs et corriger les copies

## 🎯 Rôle
Publier un **devoir** (consignes, échéance, barème, lien ou fichier) vers une ou
plusieurs classes, puis **corriger les copies déposées** par les élèves : valider,
noter, ou renvoyer pour **nouvelle soumission**.

## ✅ Prérequis
1. Être connecté à EduStaff (page 17.1) avec classes et matières affectées.
2. Classes et matières créées sur le web (PARTIE 03).
3. Les élèves rendent leurs copies depuis **EduStudent** (page 18.x) — le dépôt
  apparaît ici dans la corbeille de correction.

## 🟢 Créer un devoir (étape par étape)
1. Accueil → tuile **« Devoirs »** (« Assignments ») → bouton **ajouter (+)**.
2. Choisissez les **classes/sections** destinataires (multi-sélection possible).
3. Choisissez la **matière**.
4. Saisissez le **titre du devoir**.
5. Rédigez les **instructions** (consignes détaillées, attendu, format).
6. Fixez la **date limite** puis l'**heure limite** (sélecteurs séparés).
7. Indiquez le **barème** (points).
8. Ajoutez un **lien** (champ URL) ou une pièce si l'écran le propose.
9. Option **« nouvelle soumission autorisée »** : si activée, précisez les **jours
   supplémentaires** accordés aux copies rejetées pour être re-rendues.
10. **Enregistrer** : le devoir part vers les élèves, avec notification.

## 🟢 Corriger les copies déposées
1. Tuile **« Devoirs »** → listez les devoirs actifs → ouvrez un devoir.
2. Écran **« Soumissions »** : chaque copie déposée par un élève apparaît avec sa
   date d'envoi.
3. Ouvrez une copie : consultez le texte/fichier/image rendu.
4. Décidez :
   - **Valider** (avec note sur le barème si demandé) ;
   - **Rejeter / renvoyer** : l'élève est autorisé à redéposer (si vous aviez activé
     la re-soumission et dans les jours supplémentaires prévus).
5. Les copies en attente apparaissent aussi dans le badge 🔔 de l'accueil : les
   traitements groupés sont plus rapides.

## ✏️ Modifier un devoir
1. Liste des devoirs → ouvrez le devoir → icône **Modifier**.
2. Tout est ajustable (classes, date limite, barème, re-soumission) — attention :
   les copies **déjà déposées** sont conservées, les nouveaux paramètres s'appliquent
   aux dépôts à venir.
3. **Mettre à jour**.

## 🔴 Supprimer un devoir
1. Ouvrir le devoir → icône **Supprimer** → confirmer.
2. ⚠️ Sans corbeille mobile : le devoir et ses consignes disparaissent pour les élèves ;
   les copies déjà soumises restent consultables un temps côté web.

## ♻️ Restaurer
- Devoir supprimé : **recréez-le** avec les mêmes consignes (gardez une copie du texte
  hors de l'app avant toute suppression).
- Copie d'élève « disparue » de la liste : l'élève a peut-être **re-supprimé** son
  dépôt — demandez-lui de redéposer, dans le délai accordé.
- Rejet sans effet (l'élève ne peut pas redéposer) : la re-soumission n'était pas
  activée sur le devoir ou le délai est passé — modifiez le devoir (point 9).

## ⚠️ Bon à savoir
- Date et heure limites sont **deux champs séparés** : un devoir « pour demain » sans
  heure est réputé limité à minuit — mieux vaut être explicite.
- Le **barème saisi ici** sert aux statistiques de la matière ; le bulletin officiel
  utilise les notes d'examen (page 17.12).
- Un devoir donné à **plusieurs classes** en une fois = une seule correction par liste,
  filtrable par classe.
- Pour générer un devoir automatiquement par IA, voyez le **générateur de devoirs**
  (page 17.13) — le rendu est identique à une saisie manuelle.
